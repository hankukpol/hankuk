## 적용 범위와 남은 데이터 조건

확인 가능한 오늘의 직접 수정 요청은 위 표대로 로컬 미리보기에 반영했다. 기존 운영 성적 화면과 운영 DB를 교체하지 않았다. 미리보기 데이터 어댑터는 독립 MOCK 자료를 읽으므로 실데이터 운영 연동·배포 완료라고 볼 수 없다.

‘진도’는 실제 등록된 시험 범위다. 문항마다 세부 단원, 재풀이 이력, 풀이시간, 오답 원인이 저장되어 있지 않아 해당 수치나 기능을 임의 생성하지 않았다. 이는 앞서 개선 제안으로 언급한 별도 확장 사항이며 오늘의 직접 UI 수정에서 누락한 기능으로 분류하지 않는다. 순위/점수 상승을 합격 확률이나 난이도 보정 실력으로 단정하지 않는다.

참조한 기존 소스: Study Hall `lib/exam-analysis-meta.ts`, `lib/morning-exam-analysis-assembler.ts`, `lib/exam-learning-plan.ts`; score-predict `src/app/exam/result/components/WrongRateTop5.tsx`, `src/app/api/analysis/wrong-rate-top/route.ts`. 이전 정기 리포트/공개 웹 비교 기록은 `regular-report-reference-review.md`에 있다.
