## 구현한 개인 자료

### 정기 모의고사

1. 같은 만점·같은 응시 과목·전과목 응시 기록만으로 6개월 평균과 첫/마지막 시험 차이를 요약한다. 일부 미응시·과목 구성 변경 기록은 해당 요약에서 제외하고 제외 수를 명시한다. 원본 월별 기록은 보관하고 기존 표에 계속 표시한다.
2. 과목별 시험 점수 비중, 내 점수/만점, 잃은 점수, 외부 평균 대비 격차를 표시한다. 잃은 점수는 만점-내 점수이며 회복 예상치가 아니다.
3. 쉬운 문항 오답 수 내림차순, 잃은 점수 내림차순으로 복습 과목을 정렬한다. 임의의 새 판정 임계값은 추가하지 않는다.
4. 해당 시험의 과목별 쉬운 오답·무응답·그 밖의 오답 번호를 중복 없이 제공한다. 정오는 수입한 O/X를 유지한다.

### 아침 모의고사

1. 과목별 쉬운 오답과 무응답 수, 응시 횟수, 시험 날짜와 진도 라벨을 연결한다.
2. 반 평균보다 낮은 단원을 격차순으로 제시하고 단원별 응시 수를 함께 표시한다. 서로 다른 과목의 원점수를 혼합해 새 위험 등급을 만들지 않는다.
3. 기존 설정에 따른 응시율·기록 부족 시 추세 판정을 보류한다. 실제 응시한 오답의 복습은 제공한다.
4. 문항이 없는 진도, 미응시 택1 과목 또는 미등록 단원을 임의로 생성하지 않는다.

### 공통 출력

- 학습 진단만 출력하는 버튼과 기존 전체 리포트 출력 버튼을 구분한다.
- 요약 자료에 재풀이→근거 확인→오답 선택지 수정→다음 복습 확인 절차 및 수기 기록란을 포함한다. 수기 기록란은 저장 기능이 아니다.
- A4 다중 페이지, 한 자리 소수점, 전체 채점표 접근 및 기존 권한을 유지한다.

## 해석 경계와 추가 데이터가 필요한 것

- 외부 석차는 파일에 포함된 응시 집단 내 위치다. 실제 시험 응시자 전체나 지역 합격선으로 확대 해석하지 않는다.
- 서로 다른 시험 간 공통 문항·동등화 자료가 없어 난이도를 보정한 실력 추정, IRT 능력치, 수능식 표준점수를 만들지 않는다.
- 현재 문항별 풀이 시간·오답 이유·재시험 결과를 수집하지 않는다. 시간 부족/마킹 실수/개념 부족을 자동 판정하지 않는다.
- 정기 문항에 단원 태그가 없으므로 조문/판례/세부 단원별 약점을 꾸며내지 않는다. 도입하려면 시험 문항-단원 매핑을 운영자가 검증해야 한다.
- 과목 과락 기준은 채용 종류별 설정·공고 버전 관리가 필요하다. 기존 DB에 없는 기준을 코드에 새로 박아 자동 과락 판정을 추가하지 않았다.
- 개인별 실행 자료는 가상 학생 데이터로 출력 검증한다. 실제 원본 아침 XLS 두 파일 검증은 여전히 별도 과제다.
- 운영 DB 마이그레이션/배포 없음. 분석 외 출결·면담·경고·채팅 파일 수정 없음.
