# 표 내부 배지 텍스트 통일

- 변경: DESIGN.md, app/globals.css, scripts/design-table-text-audit.mjs.
- 전체 HTML 표의 상태/경고/직렬/분류 배지는 배경·테두리·그림자를 제거하고 글자색 유지.
- 행 액션은 외곽 상자를 제거하고 클릭 영역·포커스 유지.
- 입력/select/checkbox 및 aria-pressed 선택 컨트롤, 표 밖 카드/필터는 유지.
- 업무 데이터와 API 변경 없음.

## 검증

localhost:3000 모의 환경에서 14개 관리자 경로와 하위 탭을 390/768/1280px로 순회했다.
131개 표시 검사, 배지/액션 483회 측정에서 스타일 위반은 0건이었다.
데이터가 없거나 카드로 전환되는 모바일 화면의 표 측정값은 0으로 기록했다.
전체 순회 중 layout.js 청크 로딩 오류 5건과 하이드레이션 오류 1건이 발생했으므로
전체 실행 오류 검사를 통과한 것으로 보고하지 않는다.

새 브라우저 컨텍스트에서 학생 명단/휴대폰/상벌점 규칙을 1280px로 재검사하여
7개 페이지/탭 검사 및 실행 오류 0건을 확인했다. 타입 검사와 diff 공백 검사는 통과했다.
모든 학생/조교 화면과 개별 모달을 실제로 열어 확인한 결과는 아니다. 해당 범위에는 공통 CSS가 적용된다.
