# Score Predict Design System

## 1. Atmosphere / signature

한국경찰학원과 소방 합격예측의 기존 운영 화면을 보존한다. 정보 밀도가 높은 수험 대시보드이며, 밝은 회색 배경과 흰색 카드, 진한 헤더를 공유한다. 서비스 강조색은 경찰 블루와 소방 레드로 분리하여 사용자·관리자 화면 전체에서 현재 서비스를 즉시 식별할 수 있게 한다. 구조와 상태 표현은 동일하게 유지한다.

Design Read: 수험생과 운영자를 위한 실시간 성적 대시보드, 기존 학원 서비스 언어, 안정적이고 직접적인 운영 UI.

- `DESIGN_VARIANCE`: 2
- `MOTION_INTENSITY`: 1
- `VISUAL_DENSITY`: 8

## 3. Typography

글꼴은 `Noto Sans KR`, `Apple SD Gothic Neo`, `Malgun Gothic`, `sans-serif`이다.

| 단계 | 크기 | 클래스 | 굵기 | 용도 |
| --- | --- | --- | --- | --- |
| Display | `48px` | `text-5xl` | 900 | 대시보드 대표 점수, 랜딩 히어로 최대 단계 |
| Hero | `36px` | `text-4xl` | 900 | 랜딩 히어로 중간 단계 |
| 큰 제목 | `30px` | `text-3xl` | 700 | 페이지 제목 |
| 수치 강조 | `24px` | `text-2xl` | 700~900 | 카드 안의 핵심 수치 |
| 섹션 제목 | `20px` | `text-xl` | 700 | 섹션 헤딩 |
| 카드 제목 | `18px` | `text-lg` | 700 | 카드·패널 헤딩 |
| 본문 강조 | `16px` | `text-base` | 600 | 강조 본문, 폼 라벨 |
| 본문 | `14px` | `text-sm` | 400 | 기본 본문 |
| 보조 설명 | `12px` | `text-xs` | 400 | 캡션, 배지, 보조 라벨 |
| 마이크로 라벨 | `10~11px` | `text-[10px]`, `text-[11px]` | 400~700 | 밀도가 높은 대시보드 지표 라벨 전용 |

- line-height는 제목 1.25~1.4, 본문 1.6, 보조 1.5를 기준으로 한다.
- 수치는 크기와 무관하게 `tabular-nums`를 우선한다.
- 마이크로 라벨은 `VISUAL_DENSITY 7`인 실시간 대시보드에 한정한다. 일반 폼과 관리자 표에는 사용하지 않는다. 신규 코드는 `10px`을 기본으로 쓰고 `11px`은 기존 화면 유지 목적으로만 남긴다.
- `36px`·`48px`은 랜딩 히어로와 대시보드 대표 수치에만 쓰고 다른 화면으로 확산하지 않는다.
- 한글 줄바꿈은 전역 `word-break: keep-all`과 `overflow-wrap: break-word`를 기본으로 한다(`globals.css`의 `@layer base`). 이 설정이 없으면 `비활성`이 `비활 / 성`처럼 어절 중간에서 잘린다. 어절 사이 줄바꿈은 정상이며, 슬래시나 괄호가 포함된 짧은 라벨(`미동의/철회`, `(과락 제외)`)처럼 한 줄을 유지해야 하는 경우에만 `whitespace-nowrap`을 추가한다.
- 표의 `<th>`와 상태·수치를 담는 짧은 `<td>`는 `whitespace-nowrap`을 사용하고, 좁은 라벨 열은 `w-24`·`w-28` 같은 명시적 너비를 지정한다. 표 전체는 `overflow-x-auto` 안에 두어 가로 스크롤로 처리한다.

## 5. Components

- 카드: 흰색 배경, slate-200 경계, 10px radius(`rounded-xl`)
- 카드 padding: `p-4`(16px) 조밀, `p-5`(20px) 기본, `p-6`(24px) 여유, `p-8`(32px) 강조 섹션. 반응형은 `p-5 sm:p-6`을 기본 패턴으로 한다
- 카드 내부의 작은 상태 박스는 `p-2`(8px), `p-3`(12px)를 사용한다
- radius 위계는 `globals.css`의 `--radius: 0.5rem`을 기준으로 계산한다. 바깥 표면일수록 크고 안쪽으로 갈수록 작아진다
  - 카드·패널: `rounded-xl` = **10px**
  - 카드 안의 중첩 표면·배지·중간 컨테이너: `rounded-lg` = **8px**
  - 폼 컨트롤과 작은 버튼: `rounded-md` = **6px**
  - 아바타·진행바·점: `rounded-full`
  - `object-cover` 이미지에만 `rounded-2xl` = 16px 허용
- 중첩된 표면은 부모보다 반드시 한 단계 작은 radius를 쓴다. 부모와 자식이 같은 radius면 경계가 겹쳐 보여 계층이 사라진다
- 주 버튼: service-600 또는 service-700 배경, 흰색 글자, 명확한 hover·focus·disabled 상태
- 보조 버튼: 흰색 배경, slate-200 경계, slate-700 글자
- 탭: 선택 시 서비스 강조색, 미선택 시 흰색과 slate 경계
- 사용자 화면의 섹션 탭: 하나의 흰색 표면 안에서 하단 2px 서비스 강조선으로 선택 상태를 표시한다. 탭마다 pill·캡슐 경계를 반복하지 않는다
- 지표 요약: 같은 크기의 작은 카드를 여러 개 나열하지 않고 하나의 흰색 표면 안에서 `divide-x`·`divide-y` 구분선으로 묶는다. 가장 중요한 지표 하나만 service-50 배경으로 강조할 수 있다
- 데이터 표: 표 전체에 외곽 경계는 최대 1개만 사용한다. `th`는 slate-50 배경과 하단 경계, `tbody`는 `divide-y`만 사용하며 셀마다 사방 `border` 또는 세로 격자선을 넣지 않는다
- 카드 안의 데이터 표: 부모 카드가 이미 경계를 제공하면 표에는 별도의 둥근 외곽 카드 경계를 추가하지 않고 상·하단 구분선만 사용한다
- 모바일 데이터 목록: 항목마다 둥근 카드를 반복하지 않는다. 하나의 목록 표면 안에서 `divide-y`로 행을 나누고, 라벨과 값은 2열 정의 목록으로 정렬한다
- 중첩 표면: 순수 정보 묶음은 `카드 안 카드`로 표현하지 않는다. 부모 표면 안에서는 배경 띠, 상단 구분선, 좌측 상태선 중 하나만 사용한다. 예외는 실제 입력 컨트롤 그룹과 경고·오류 상태다
- 차트: 흰색 카드, chart-grid 격자, chart-tick 레이블, mine 색은 chart-mine
- 상태: 로딩은 slate, 빈 상태는 amber, 오류는 rose 계열의 기존 표현 유지
- 관리자 내비게이션: service-700 배경, 흰색 활성 글자, service-200~400 보조 글자
- 공지사항 게시판: 데스크톱 열 너비는 번호 96px(`w-24`), 작성자 112px(`w-28`), 등록일 144px(`w-36`)을 사용하고 제목 열은 남은 폭을 사용한다. 검색 영역은 최대 384px(`max-w-sm`), 페이지 버튼은 40px(`size-10`)로 통일한다
- 사용자 페이지 CTA: 주 행동은 service-600 배경, 보조 행동은 흰색+slate 경계로 통일한다. 동일한 행동 영역 안에서 검정 CTA와 서비스 블루 CTA를 혼용하지 않는다
- 관리자 HTML 에디터: 기존 배너 관리와 공지 관리는 동일한 SunEditor 도구막대를 공유한다. 편집 영역 기본 높이는 공지 360px, 배너 350~400px이며, slate-300 경계와 `rounded-md`, service-600 포커스 링을 사용한다. 공개 본문의 제목·목록·표·인용·이미지는 본문 타이포그래피와 spacing 토큰 안에서 반응형으로 표시한다

모든 인터랙션은 hover, active, focus-visible, disabled 상태를 보존한다.

## 6. Motion

- 기본 전환: 150~300ms ease-out
- 관리자 모바일 사이드바: 기존 300ms transform 전환 유지
- 진행 표시: 기존 500ms 전환 유지
- 새 레이아웃 애니메이션은 추가하지 않는다.
- `prefers-reduced-motion` 환경에서는 비필수 transition과 transform을 제거한다.

## 7. Depth

경계선 중심의 깊이 체계를 사용한다.

- Level 0: 페이지 배경 slate-100
- Level 1: 흰색 카드 + 1px slate-200 경계. **그림자를 쓰지 않는다**
- Level 2: 문서 흐름 안의 모든 카드·패널·표. Level 1과 동일하며 배경 차이로만 구분한다
- Level 3: 문서 흐름 밖에 떠 있는 요소(드롭다운, 팝오버, 모바일 사이드바)의 `shadow-lg`
- Level 4: 모달 다이얼로그와 콘텐츠 위를 덮는 오버레이의 `shadow-xl`

**그림자는 문서 흐름 밖으로 떠 있는 요소에만 쓴다.** 페이지 안에 자리를 차지하는 카드·패널·표·통계 타일에는 그림자를 넣지 않고 1px 경계선만 사용한다. 카드마다 그림자를 깔면 화면 전체가 균질하게 들뜬 느낌이 되어 정보 위계가 사라진다.

- 카드 hover는 그림자가 아니라 경계선으로 표현한다: `hover:border-slate-300` 또는 서비스 색 경계
- `hover:shadow-md`, `hover:-translate-y-*` 같은 부양 효과는 사용하지 않는다(`MOTION_INTENSITY 1`)
- `components/ui`의 `button`·`input`이 쓰는 `shadow-xs`는 shadcn 기반 레이어이므로 앱 코드에서 덮어쓰지 않는다. 단 `card` 프리미티브는 위 원칙에 따라 그림자를 제거한 상태를 유지한다

색상이 지정된 그림자(`shadow-slate-900/10` 등), `shadow-2xl`, 글래스모피즘은 도입하지 않는다.

사용자 데이터 화면에서 한 콘텐츠 계층에는 한 번만 경계선을 쓴다. `섹션 카드 → 내부 카드 → 셀 사방 경계`처럼 3중으로 깊이를 표현하지 않으며, 내부 계층은 배경 차이 또는 1px 구분선으로만 나눈다.

## 8. 2026년 하반기 경찰 사전등록 프로모션

Figma 원본 노드 `106:2`에서 제작된 프로모션 랜딩은 일반 대시보드와 분리된 캠페인 표면이다. 전체 구조와 자산 배치는 원본을 유지하되, 실제 운영 기능과 다른 예측 등급·과장 표현은 사용하지 않는다.

- 캠페인 전경: `rgb(34 34 34)`
- 캠페인 보조 전경: `rgb(85 85 85)`
- 캠페인 배경: `rgb(255 255 255)`, `rgb(241 246 250)`, `rgb(239 239 239)`
- 캠페인 강조: `rgb(9 0 255)`, `rgb(0 46 246)`
- 캠페인 CTA: Figma 원본의 직사각형 검정 CTA `rgb(0 0 0)`를 해당 랜딩 안에서만 사용한다
- 캠페인 포커스 링: `rgb(50 107 255)` 4px
- 캠페인 카드 radius: 16px, 태그 radius: 4px
- 캠페인 본문 최대폭: 1060px, 히어로 최대폭: 1328px
- `EVENT 02`는 1920px 원본에서 708px 높이의 흰색 2열 섹션이며, 설명과 단일 경품 콜라주를 좌우로 배치한다
- `EVENT 03`은 1920px 원본에서 883px 높이의 `rgb(241 246 250)` 섹션이며, 내부 설명회 카드는 최대 1060px·높이 360px·radius 16px를 사용한다
- `EVENT 03` 강사 이미지는 데스크톱에서 최대 299px 너비를 사용하고, 태블릿·모바일에서는 카드 흐름 안에서 비율을 유지한다
- `EVENT 03` 카드 제목은 Figma 레이어 `124:221` 기준 Pretendard Bold 40px, 자간 -1px을 사용한다
- 프로모션 이미지는 운영 Supabase Storage의 `promotions/police/2026-second` 경로에서 제공한다
- CTA는 모두 현재 사이트의 사전등록 모달을 열며, 별도 페이지 이동이나 중복 폼을 만들지 않는다
- ‘확실권·유력권·가능권’, ‘가장 정확한’, ‘빅데이터’처럼 실측 보정 또는 근거가 필요한 표현은 캠페인 문구와 이미지에 사용하지 않는다
