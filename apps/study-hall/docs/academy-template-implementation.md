## 작업 위치와 기존 코드 재사용

- 작업 폴더: `D:/Codex/worktrees/study-hall-academy-templates-20260914/apps/study-hall`.

## 관리자 사용 흐름

1. 기존 설정 메뉴에서 해당 항목을 편집한다.
2. 저장하면 변경 전/후와 적용일을 확인한다. 취소하면 입력 초안을 유지한다.
3. 오늘 출결이나 점수 기록이 있으면 계산 설정은 내일 이후로 예약한다. 과거 기록을 소급 변경하지 않는다.
4. 같은 날짜에 다른 메뉴를 추가 수정하면 기존 예약과 병합한다. 이전 예약은 취소 이력으로 남기고, 합쳐진 예약 한 건을 유지한다.
5. 설정 → 템플릿에서 현재 설정을 독립 사본으로 저장하거나 공통·빈 템플릿·저장 사본을 불러온다. 내용 편집은 기존 메뉴를 사용한다. 파일 가져오기/내보내기는 허용 필드와 참조를 검증한다.
6. 예약일의 인증된 요청 또는 자동 마감 전에 적용한다. 예약 이후 다른 설정·보호 대상이 바뀌면 재검토 상태로 남긴다.

## 연결 범위와 기록 보호

| 영역 | 실제 연결 |
| --- | --- |
| 시간표·운영일·지각 | 기존 교시/운영 규칙 저장, 실제 도착 시각의 학원별 지각 분 판정. 일괄 저장 시각을 도착 시각으로 보지 않음 |
| 상벌점·개근·시험 | 기존 규칙과 일/주/월 마감에서 해당 날짜의 설정 사용. 시험 시작일·요일을 임의 보정하지 않음 |
| 휴무·반휴·병가 | 기존 승인/취소/미사용 정산에 날짜별 규정·교시 적용. 활성 관리규정에서 반휴 적용 교시 수 편집 가능, 기존 규정의 미설정 값은 종전 3교시 유지 |
| 휴대폰 | 개인 체크, 일괄 대여, 과거 기록 조회가 해당 날짜의 교시·출석 연동·관리규정을 사용 |
| 좌석·수납 | 템플릿은 배치/요금 설정만 복사. 배정 학생·실제 약정·납부·출결·성적·점수는 복사하거나 수정하지 않음 |
| 개인정보·권한 | 학원 필터, 역할 검증, 외부 참조 차단. 직원 계정·학생·선택자습 신청은 템플릿에서 제외 |

- 기존 관리규정의 안내 문구, 휴식 안내, 순찰/학습목표 안내 수치는 안내 성격이다. 실제 순찰 여부나 학습 수행을 자동 측정하는 기능을 새로 만든 것은 아니다.
- 좌석 배정/이동, 직원·학원 기본 신원 정보, 표시 순서 등 운영 작업은 기존 전용 경로를 유지한다. 이를 설정 사본에 개인정보와 함께 넣지 않는다. 설정을 바꾸면 예약의 기준 버전이 달라져 덮어쓰기를 막는다.
- 설정 관련 기존 API도 같은 스냅샷 적용 서비스를 사용한다. 미리보기를 지원하지 않는 구형 클라이언트의 당일 계산 변경은 당일 운영 기록이 있으면 오류로 차단한다.
- 변경한 규칙은 기존 기록을 삭제하지 않도록 비활성화한다. 사용 중인 좌석의 구조 변경, 유효하지 않은 규칙 연결, 미리보기 후 동시 변경을 차단한다.
- 휴가 취소는 승인 시 저장한 출결 스냅샷으로 복원하고, 승인 후 사람이 별도 수정한 칸은 보존한다. 이전 버전 승인 기록은 해당 날짜의 규정/교시로 판정한다.
