## 계산·업무 흐름 변경

- 상점과 벌점을 **월별로 따로** 집계한다. 상점으로 벌점이 상쇄되지 않는다. 월 변경은 조회 기간을 바꾸며 이력은 삭제하지 않는다.
- 월 벌점 10: 관리주의 / 20: 정식 면담·7일 개선미션 / 25: 최종경고·개선확약 / 30: 이용종료 검토. 관리자·학생·경고·면담·통계 화면의 값과 명칭을 연결했다.
- 학생 상세의 ‘상점 추가로 경고 단계 낮추기’는 경찰 새 규정에서 제공하지 않는다. 오류가 있으면 잘못된 원기록을 정정한다.
- 상점 순위 동점은 휴일권 미사용 개수를 우선한다. 보상 대상 월과 기간은 조회 조건으로 확인한다.
- 조교가 출석을 저장하는 것만으로 벌점을 확정하지 않는다. 관리규정 화면에서 인정사유를 확인한 후 날짜별 후보를 확정한다. 재확정해도 중복 생성하지 않는다. 같은 날짜·학생·규칙으로 수동 부과한 건은 자동 후보에서 제외하므로 별개 행위는 개별 기록을 확인한다.
- 전체 무단결석과 교시별 벌점을 중복 부과하지 않는다. 누락·인정결석·휴일권을 무단결석으로 간주하지 않는다.
- 평일 5교시 신청은 학생·기간·요일별로 저장한다. 신청 중복은 차단하고, 종료 시 오늘과 과거 기록은 유지한다.
- 휴대폰 단기 예외는 DB 규정의 10분 반납기한과 사유를 기록한다. 장시간 용무는 관리자가 종료시각·장소·목적을 기록한다. 반출·반납 이력을 보존하고 장시간 일괄 대여를 차단한다.
- 최근 7일 무사유 중도퇴실 2회 면담, 3회 7일 개선미션 / 월 무단입실·불응 2회 심의 / 최근 7일 휴대폰 예외 3회 검토를 관리규정 화면에 표시한다.
- 휴일권 월 2회·미사용 개당 +2. 당일·사후 휴일권 승인은 예외 사유를 요구한다. 건강 인정사유는 확인 기록으로 승인하며 기존 월 1회 설정으로 차단하지 않는다.

관리자·조교·학생 화면이 동일한 규정 안내를 공유한다. 다음은 단순 점수만으로 자동 판정하지 않는다.

- `scripts/restart-police-policy.ts`: 기본은 미리보기. 확정된 벌점표 결정을 읽고 `--apply`가 있어야 쓰기 실행
- `tests/restart-policy.test.ts`: 핵심 규정 테스트
- `prisma/migrations/20260908000000_management_policy/migration.sql`: 빈 JSONB 필드 추가

완료 순서: 벌점표 결정 확인 → 분리한 코드 검토·운영 배포 → 경찰 운영 설정 적용 → 캐시 갱신 → 운영 화면·DB 재검증. 전체 변경을 일괄 커밋·배포하지 않았다.

적용 도구는 기존 교시 ID와 과거 기록을 보존하고, 다른 직렬의 설정·교시·상벌점 규칙이 달라지면 트랜잭션을 롤백한다. 이미 적용한 규정은 신청 내역 보호를 위해 재실행으로 덮어쓰지 않는다. 적용 전 스냅샷은 `.local`에 저장한다.

미리보기: `node --import tsx scripts/restart-police-policy.ts`

확정된 적용 명령은 `--apply --conflicts=table`이다. 반드시 배포 환경의 `schema=study_hall` 연결과 `MOCK_MODE=false`를 확인한다. 로컬에서 원격 DB를 사용할 때는 프로젝트의 기존 원격 접근 허용 설정도 명시적으로 필요하다.

## 운영 시 확인할 사항

- **평일 5교시:** 관리규정 화면에서 실제 신청 학생과 기간을 등록한다. 기존 학생 전체를 임의로 신청 처리하지 않았으므로 최초 신청 내역은 비어 있다.
- **출결 벌점:** 조교가 출결을 입력한 뒤 관리자가 인정사유를 확인하고 관리규정 화면에서 날짜별 벌점 후보를 확정한다.
- **직접 DB 설정 변경 후:** 설정 캐시(5분)가 남을 수 있으므로 배포 프로젝트에서 `periods:police`, `division-settings:police` 및 관련 대시보드·보고서 태그를 갱신하고 화면을 확인한다. 이번 적용에서는 Vercel의 캐시 무효화 명령으로 갱신을 완료했다.
- 변경 전후 스냅샷과 검증 결과는 원래 작업 폴더의 `.local/restart-policy-v3.1/release-evidence`에 보관했다. 운영 DB에는 검증용 학생·벌점·출결을 생성하지 않았다.
