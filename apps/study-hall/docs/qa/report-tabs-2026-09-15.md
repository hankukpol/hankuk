# 성적 분석 탭 내부 표 구성

## 확정 범위

운영자의 최종 요청에 따라 관리자 개인 성적 분석의 6개 항목 탭은 유지한다. 각 탭 본문은 단일 열로 구성하고 성적 요약, 문항 결과, 복습 문항을 표로 묶는다. 학습 진단 및 과목별 분석은 드롭다운으로 반드시 한 과목만 선택한다. 전체 과목 옵션은 제공하지 않는다. 기본은 첫 과목이며 과목이 하나면 선택창을 생략한다. 전체 채점표의 펼침 기능과 인쇄용 전체 과목 DOM은 유지한다.

학생 포털의 과목 선택과 요약 격자는 유지한다. 계산, 조회 조건, 권한, 학원별 설정 및 API 변경 없음.

- 문서 가로 넘침, 관리자 지표 카드 잔존: 0건. 각 과목 선택 시 정확히 해당 과목 하나만 표시되는지 확인.
- 정기 학습 진단 데스크톱 및 아침 요약 모바일 스크린샷 육안 확인.
- 기존 성적·복습·인쇄 테스트 22개, 관리자/학생 표시 분리 테스트 2개 통과.

- 전체/진단 인쇄 × 정기/아침 × 390/768/1280px: 12개 조합 재검증 통과. PDF 4개 재생성.
- 운영 빌드와 실물 출력은 이번 변경에서 실행하지 않음. 커밋·푸시·배포 없음.
