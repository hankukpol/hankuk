# 로컬 확인 서버 운영

2026-09-15 사용자 요청에 따라 확인용 주소를 하나로 통일합니다.

- 사용자 확인 주소: http://localhost:3000
- 소스: main 작업본의 apps/study-hall
- 컨테이너: study-hall-dev-1 (compose.yaml)
- 관리규정·휴대폰: /police/admin/settings/rules?section=policy
- 실행: 이 폴더에서 docker compose up -d dev
- 중지: docker compose stop dev (볼륨 삭제 금지)

## 에이전트 협업

사용자에게 3110, 3017 또는 기능별 별도 서버 주소를 안내하지 않습니다.
기능 worktree는 개발 용도로 유지할 수 있지만, 확인 요청 전 담당자와 조율하여
최신 기능 및 미커밋 디자인 변경을 main 로컬 작업본에 함께 반영합니다.
서버 교체·소스 동기화는 한 담당자만 진행하고, 작업 중인 파일과 테스트 데이터를 보존합니다.
로컬 통합은 Git 커밋·푸시·운영 배포·운영 DB 변경 승인이 아닙니다.

## 확인 데이터

확인 서버는 MOCK_MODE=true이며 운영 DB가 아닙니다.
통합 시 기존 3110의 학원 규정·등원 테스트 데이터를 사용했습니다.
이전 3000과 3110의 원본 mock 파일은 .local/server-integration-20260915/에 별도로 보존했습니다.
두 데이터의 기록을 임의 병합하지 않았습니다. 백업은 Git 및 공개 경로에 포함하지 않습니다.
3110 컨테이너는 데이터 보존을 위해 삭제하지 않고 중지합니다.
기기 인증은 세션 설정에 따라 다시 승인해야 할 수 있습니다.
