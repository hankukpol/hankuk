# 경찰·소방 합격예측 모델 운영 기준

## 핵심 원칙

- 경찰과 소방은 UI 틀만 공유하고 채점, 과락, 가산점, 모집단, 합격배수, 예측 모델을 서로 공유하지 않는다.
- 외부 업체의 비공개 계산식을 동일하게 복제한다고 표현하지 않는다.
- 표본 순위와 실제 응시자 전체의 순위는 서로 다른 척도다. 두 순위를 빼거나 나누어 `합격선까지 N등`, `N등 여유` 같은 값을 만들지 않는다.
- 합격 등급보다 표본 내 점수·등수·상위 백분율을 우선 제공한다.

## 경찰

### 필기 제도

- 공채와 경행경채 모두 회차별 `Exam.policeWrittenPassMultiple`을 사용한다.
- 2026년 2차의 필기 합격배수는 `2.0`이며 동점자는 모두 합격 처리한다.
- 미설정 회차는 현행값 `2.0`으로 대체하지만, 과거 회차는 관리자에서 당시 배수와 모델 버전을 명시한다.
- 2배수는 실제 응시자 전체에 적용되는 제도 정보로만 표시하고 표본 순위와 연산하지 않는다.

### 법정 가산점

- 취업지원대상자 5%·10%, 의사상자 3%·5%를 경찰 필기 점수에 적용한다.
- 어느 한 과목이라도 만점의 40% 미만이면 모든 필기 가산점을 적용하지 않는다.
- 취업지원대상자는 모집인원 4명 이상, 의사상자는 10명 이상일 때 적용한다.
- 실제 출원인원이 모집인원 이하이면 최소 모집인원 예외를 적용한다.
- 출원인원이 아직 없고 최소 모집인원 미만이면 가산점은 잠정 0점으로 채점하고, 출원인원 확정 후 자동 재채점한다.
- 표본 상위권으로 법정 30%·10% 상한을 추정하거나 제출을 차단하지 않는다. 수혜 추정치는 캘리브레이션 집계로만 보존한다.

### 등급 공개

- 모델 버전: `police-2026-2x-rank-first-v2`
- 현재 모델은 실측 캘리브레이션 전이므로 확실권·유력권·가능권·도전권을 기본 OFF로 둔다.
- 서버 응답에서도 등급, 등급 경계, 예상 합격선, 여유 등수를 `null` 또는 빈 배열로 반환한다.
- 화면은 `입력자 N명 중 M등`, `표본 상위 X%`, 원점수·가산점 적용 여부를 정상 결과로 제공한다.
- 향후 등급 활성화에는 아래 조건을 모두 요구한다.
  - 운영 기능 플래그 ON
  - 지역별 실측 캘리브레이션 완료
  - 정확한 출원인원 존재
  - 유효 입력자 30명 이상
  - 유효 입력자 `모집인원 × 2` 이상
  - 출원인원 대비 유효 입력자 30% 이상

## 캘리브레이션 스냅샷

- 시점: 시험일 마감, D+1, D+2, D+4, 공식 필기 발표일
- 저장: 시험·지역·채용유형, 모집/출원인원, 적용 배수와 모델 버전, 유효/과락/의심 건수, 원점수·가산점 반영 총점 분포와 누적 순위, 경계 동점 인원, 과목별 원점수 분포, 가산점 유형별 표본 수
- 공식 발표 후 저장: 공식 필기 합격선, 실제 필기 합격인원, 원점수/가산점 반영 기준, 공식/타사 출처 구분과 출처 링크
- 이름, 전화번호, 응시번호, 답안 등 개인정보는 저장하지 않는다.

## 소방

- 모델 버전: `fire-role-gender-sample-v1`
- 공채·구조·소방학과·구급과 성별 모집단, 소방 과목, 기존 합격배수 정책을 유지한다.
- 경찰 2배수, 경찰 법정 가산점 판정, 경찰 등급 비공개 정책을 소방 계산에 적용하지 않는다.
- 취업지원대상자 5%·10%는 모집인원 4명 이상, 의사상자 3%·5%는 모집인원 10명 이상일 때만 적용한다.
- 소방 필기 법정 가산점은 과목별 만점의 40% 이상을 득점한 과목에만 적용하고, 총점 60% 미만 과락이면 모두 제외한다.
- 자격증 가산점은 필기 법정 가산점과 분리된 소방 최종 환산점수 항목으로 유지한다.
- 법정 수혜 인원 상한은 실제 전체 응시자와 공식 합격 결과로 확정되는 값이다. 서비스 표본으로 추정해 답안 제출이나 수정을 차단하지 않는다.
- 최소 모집인원 미달 시 답안은 정상 접수하고 해당 법정 가산점만 0점으로 처리하며, 모집인원 변경 후 기존 제출을 자동 재채점한다.
