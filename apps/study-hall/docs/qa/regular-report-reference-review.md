# 정기모의고사 리포트 참고 프로젝트 분석

검토일: 2026-09-16. 참고 소스: G:/앱 프로그램/정기모의고사 성적/Code.gs, Index.html. 로컬 소스와 두 검증 스크립트를 확인했으며 Apps Script 배포나 Google Sheets는 변경하지 않았다.

## 결론

정기는 한 회차의 전과목 종합 평가로 구성한다. 최상단 공통 과목 선택을 없애고 종합 분석 → 과목별 분석 → 최근 6개월 추이 → 문항 분석으로 분리한다. 과목 선택은 과목 상세·문항 탭 안에서만 사용한다. 정기의 문항 시험일은 상단 시험 날짜와 같으므로 중복 선택기를 제거한다. 아침 시험은 기간 안에 여러 날짜가 있으므로 날짜별 문항 탐색을 유지한다.

## 참고 소스에서 확인한 구성

- Index.html 80행 이후: 총점, 전체·지역 석차 및 위치, 종합 현황, 과목별 성취도, 문항 분석, 지역 분석, 성적 분포.
- Code.gs 1195행 이후: 상위 비율과 동점 보정 백분위를 분리한다. 총점 순 상위 10%·30% 집단의 총점·과목 평균을 산출한다.
- Code.gs 1221행 이후: 과목 점수·만점·평균·석차·상위비율·득점률을 산출한다.
- Code.gs 1387행 이후: 정오 개수, 어려운 문항 정답, 정답률 높은 오답을 분류한다.
- getStudentReport는 선택한 examId 한 회차를 반환한다. 최근 6개월 추이 기능은 해당 소스에서 확인되지 않았다.
- verify-police-score-only.js 및 verify-police-import-safety.js 모두 PASS.

## 스터디 홀 적용 설계

| 구역 | 표시 내용 | 데이터/계산 |
|---|---|---|
| 종합 분석 | 총점/만점, 전체 석차·응시 인원, 상위 비율, 전체 평균 대비 점수 차이, 상위 10%·30% 평균, 분포 속 내 위치 | regular.myScore, session, ranks.external, stats.external, distribution |
| 전과목 비교 | 과목별 점수/만점, 전체 평균, 상위 집단 평균, 평균 대비 차이, 과목 석차 및 득점률 레이더 | regular.stats.subjects; 서로 다른 만점은 득점률로 비교 |
| 과목별 분석 | 과목별 약점, 오답·미응답, 우선 복습 문항, 선택률 | 선택 과목의 문항·배점·전체 정답률; 과목 선택은 이 영역 내부에 배치 |
| 최근 6개월 | 총점 및 과목별 추이, 전체 평균 대비 차이, 상위 비율 변화, 첫 회차 대비·직전 대비 증감 | existing regular.history 및 comparisons 결합 |
| 문항 분석 | 과목/번호/내 답/정답/정오/배점/전체 정답률/선택지 선택률 | 현재 회차 전과목 기본; 과목·오답 필터; 우리 학원 정답률 열 제거 |

현재 lib/exam-analysis-assembler.ts의 regularHistoryRange/assembleRegularHistory에 선택 시험이 속한 달을 포함한 6개 달 조회가 이미 있다. 예: 2026-09-16 선택 시 2026-04-01~09-16. history에는 회차별 총점·만점·과목 점수·전체 순위·인원·상위 비율·부분성적 여부가 있다. comparisons에서 동일 회차의 과목 평균을 결합할 수 있다. 총점 전체 평균은 회차 전체 응시 집단이 동일하고 완전한 집계인지 확인한 뒤 사용한다.

## 변화 해석 원칙

- 점수 상승만으로 실력 상승을 확정하지 않는다. 총점 증감과 전체 평균 대비 차이, 상위 비율 변화를 같이 보여준다.
- 상위 비율은 낮아질수록 유리하다. 예: 30%→20%는 10%p 개선이다. 백분위와 반대 방향이므로 둘을 같은 명칭으로 표시하지 않는다.
- 6개월 내 실제 기록만 표시하고 미응시·자료 없음은 0점으로 채우지 않는다. 현재 응시 회차/기록 보유 개월 수를 명시한다.
- 부분 성적은 전과목 완전 성적과 같은 총점 추이에 섞지 않는다. 만점·과목 구성이 바뀌면 구분하거나 비교 제한을 표시한다.
- 단순한 1~2회 증감으로 지속 상승 판정을 하지 않는다. 수치 변화부터 표시하며 자동 판정 기준은 학원 설정과 연동한다.

## 그대로 가져오지 않을 부분

- 참고 프로젝트의 상위 비율 기반 합격권 문구: 실제 합격 확률 근거가 아니므로 가져오지 않는다.
- 과목 균형 계산의 응시자 최고점 분모: 실제 과목 만점 기준으로 계산한다.
- 참고 프로젝트의 80%/40% 문항 분류 임계값: 기존 학원별 분석 설정을 사용한다.
- 100문항·100분은 사용자가 설명한 해당 시험 운영 방식이다. 공통 제품의 모든 학원 시험에 하드코딩하지 않는다. 참고 소스는 100문항·250점 가져오기 검증을 사용하지만 현재 미리보기 fixture의 배점과 같다고 가정하지 않는다.
- 우리 학원과 전체 응시자 비교는 이번 개인 리포트에서 제외한다. 전체 응시자 비교로 통일하되 가져온 파일이 일부 집단이면 전국 전체라고 부르지 않는다.

## 구현 검증 기준

정기 종합은 과목 선택 없이 전과목 총점으로 시작. 정기 중복 날짜 선택 없음. 전체 응시자 기준만 표시. 6개월 실제 회차와 결측 표시. 전과목 인쇄와 과목 상세 인쇄 범위 명확화. 아침 다회차 탐색 보존. 기존 운영 페이지 및 계산 계약 보존. 6개월 fixture, 부분성적·동점·만점 변경·한 회차·무자료를 로컬에서 검증한다.

이번 작업은 참고 프로젝트 검토 및 적용 설계 문서 작성이다. 해당 설계의 화면 구현 완료를 의미하지 않는다.
