# 성적 분석 재점검 및 코드 리뷰

검토 범위는 정기·아침 개인 성적 분석의 로컬 미리보기다. 이전 요청 대응표, 최근 보완 코드, 실제 브라우저 동작을 대조했고 별도 검토자가 계산·저장·권한 경로를 읽고 순수 함수로 오류를 재현했다. 기존 untracked 미리보기 코드는 파일 내용으로 검토했다. `git diff`만으로 리뷰하지 않았다.

## 발견 사항과 처리

| 중요도 | 재현한 문제 | 수정 |
|---|---|---|
| P2 | 채점 2회 중 비교 통계는 1회뿐이어도 최소 비교 2회 조건을 통과해 취약 판정 | 같은 문항의 내 결과와 전체 통계가 모두 있는 비교 회차만 최소 조건에 포함. 응시 회차와 비교 회차를 별도 열로 표시 |
| P2 | 10월 예약 정책이 있는 상태에서 9월 정책을 바꾸면 변경 이력의 이전 값이 10월 값 | 미리보기·계산·저장 이력이 같은 적용일 조회를 사용. 미래 예약과 원래 정책 이력은 유지 |
| P2 | 복수 정답 `1,2`에서 개별 선택지를 제출하면 무조건 오답 기록, 전체 문자열은 선택지 검증 오류 | 복수 정답 인정 방식이 없는 자료는 자동 채점 보류. 서버에서 잘못된 이력 생성을 거부하고 화면에 이유 표시. 기존 채점·복습 예약 유지 |
| P2 | 과거 시험의 제한 시간을 현재 변경된 설정으로 표시 | 기록 기능 사용 여부는 현재 설정, 시험 제한 시간 비교는 해당 시험일의 설정 사용 |
| P2 | 시간 기록의 시험일을 바꿔도 이전 ‘시간 부족’ 체크가 남음 | 시험 변경 시 해당 체크도 초기화. 제출 요청이 새 회차와 초기화된 값인지 확인 |
| 가독성 | 비교 회차 열 추가 후 좁은 PC 표에서 한글 어절이 잘림 | 진도·판단·다음 학습 열에 폭 배분, 모바일 2열·중간 폭 4열 값 배치. 날짜·수치 열 구분 유지 |

복수 정답 문자열만으로 ‘어느 하나를 고르면 정답’과 ‘모두 골라야 정답’을 구별할 수 없다. 이를 임의로 결정하지 않았다. 이 형식의 자동 재풀이 채점을 사용하려면 문항별 채점 방식 자료가 필요하다.

## 검증 및 리뷰 결과

- 수정 전 순수 함수 회귀 검사에서 3건 실패를 재현했다. 수정 후 기존 계산·학원 분리·권한 검사를 포함한 52개 테스트가 통과했다.
- 수정 전 브라우저에서 과거 제한 시간이 100분 대신 45분으로 표시되고, 회차 변경 후 시간 부족 체크가 유지됨을 재현했다.
- 새 Chrome 검증은 과거 기준, 회차 변경 후 전송 값, 독립 비교 회차 열, 복수 정답 보류와 예약 유지, 단일 답안 입력, 학생 본인 및 학원 접근 제한의 6개 그룹이다.
- 정책·복수 정답 브라우저 검증은 해당 브라우저의 API 응답에만 조건을 주입했다. 실제 저장소와 원래 성적을 변경하지 않았고 검증 전후 문서의 동일성을 확인했다.
- 별도 검토자가 수정된 계산·저장 코드와 회귀 검사를 재리뷰했다. 지적한 3건이 해소됐고 해당 수정 범위에 추가 결함을 찾지 못했다. 이것은 모든 운영 환경에 결함이 없다는 선언이 아니다.
- 아침 복습 후 정기 문항 적용은 기존 안내대로 조회 종료일까지의 결과를 보여준다. 시작일을 적용하지 않는 점을 검토했으나 명시된 계산 계약과 일치하므로 오류로 집계하지 않았다.

현재 실행 증거: `.superloopy/evidence/frontend/2026-09-17-learning-review/`. 브라우저·빌드·디자인·성능의 최종 결과는 해당 폴더의 `VISUAL_QA.md`, `PERF.md`, `evidence-record.json`에 기록한다.

최종 결과는 단위 테스트 52개·브라우저 6개 그룹·프로덕션 빌드 통과, 디자인 규격 위반 0개다. 성능 중앙값은 정기 모바일 90/PC 99, 아침 모바일 93/PC 99이며 접근성·권장사항·SEO는 전 실행 100이다. 서버 시작 직후 첫 정기 모바일 실행은 63점/LCP 14.3초로 느렸다. 초기 접속 지연은 남은 성능 개선 대상으로 기록하며 반복 실행 점수만으로 이 한계를 감추지 않는다.

## 범위와 남은 조건

운영 저장소 연결·마이그레이션·배포는 실행하지 않았다. 로컬 검증 자료는 실제 성적 원장이 아니며 실제 과목 배점은 이전에 표시한 합성 가정을 유지한다. 읽기·쓰기 권한 검증은 로컬 MOCK 인증 및 학원 분리 조건의 결과다. 실제 운영 인증·데이터로 완료됐다고 볼 수 없다. 컴포넌트 복잡도와 JavaScript 기반 폼에 대한 정적 검사 권고는 기록하고, 이번 오류 수정과 무관한 대규모 재구성은 진행하지 않았다.
