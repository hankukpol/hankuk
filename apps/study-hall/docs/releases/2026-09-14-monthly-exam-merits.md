# 성적 순위 상점 월별 지급 정정

운영자 확인: 성적 순위 상점은 매일 또는 시험 회차별 지급이 아니라 월별 지급이다. 기존 `rank:<시험>` 생성은 잘못된 구현이다.

- 진행 중인 달에는 순위 상점을 지급하지 않는다. 다음 달 일일 마감에서 지난달을 정산하며, 성적 수정·삭제·설정 재저장 시에도 월별 한 건을 유지한다.
- 아침모의고사 월간 1등, 정기모의고사 월간 1·2·3등을 각각 집계한다. 같은 종류의 시험 파일이 여러 개여도 학생별 월별로 중복 지급하지 않는다.
- 학원 설정의 `rankAggregation`으로 응시한 시험의 월평균(`AVERAGE`, 기본) 또는 월 누적(`TOTAL`)을 선택한다. 회차별 만점으로 100점 환산 후 계산한다. 미응시를 0점으로 넣지 않으며 미응시 벌점은 별도이다.
- 해당 학원 재원 학생 중 응시일에 수강 기간·직렬이 맞는 완전한 점수만 집계한다. 학생 직렬별로 비교한다. `rankTieBreak`는 공동 순위 또는 응시 횟수→순공시간을 선택하며, 모든 기준이 같으면 공동 순위 후 다음 순위를 건너뛴다. 순공시간은 기존 학습 랭킹과 같은 계산 함수를 사용한다. 외부 순위·부분 점수·유효하지 않은 만점은 사용하지 않는다.
- 경찰은 최신 운영 문서 `f6f8c4c`에 따라 월 누적 점수, 동점 시 응시 횟수→순공시간으로 설정한다. 다른 학원의 설정에는 강제하지 않는다.
- 학원별 시작일·요일·휴강일, 미응시 벌점, 월 개근 상점은 유지한다. 다른 학원 운영 설정을 변경하지 않는다.
- 이번 경찰 운영 정정 대상은 2026-09-14 조현준에게 생성된 회차별 1등 +3점 1건이다. 배포 후 해당 자동 기록만 정정하고 감사 이력을 남긴다. 수동 기록은 보존한다.

## 검증 기준

첫 시험/월말 당일 미지급, 다음 달 월 1회, 여러 회차의 우승자가 달라져도 월간 집계로 단일 지급, 평균/누적 및 만점 환산, 아침/정기 분리, 직렬·학원 분리, 공동 순위, 재저장·재가져오기 멱등성, 기존 오지급 회수, 실제 PostgreSQL 트랜잭션 롤백을 검증한다.

검증 완료: 단위/회귀 760개, typecheck, lint, 프로덕션 빌드와 HTTP 권한/학원 분리/가져오기/분석/내보내기 통합 검사 통과. 격리 PostgreSQL에서 첫날 및 월말 미지급→다음 달 1건→중복 실행 유지, 기존 일별 상점 정정과 롤백을 확인했다. 390/768/1280px 문서 가로 넘침 0, 모바일 선택 컨트롤 44px/15px, 월간 기준 저장 후 재접속 유지 확인.
