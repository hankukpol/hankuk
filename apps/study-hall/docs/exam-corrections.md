# 성적 정정

관리자 → 시험 성적 → 아침/정기 → 가져오기 → 가져오기 이력의 **성적 정정**에서 사용한다.

- 이름·수험번호로 기존 응시 학생을 찾고 실제 응시 학생을 선택한다. 학생 명단의 학번은 변경하지 않는다.
- 문항 답안과 정답/오답 판정을 수정한다. 문항 배점은 가져온 시험의 배점을 사용하며 총점 직접 입력은 허용하지 않는다.
- 정정 사유를 입력하고 변경 확인 후 확정한다. 학생 연결, 문항 응답, 과목 점수, 총점, 반 석차, 해당 월 자동 상벌점과 이력을 함께 저장한다.
- 이력에는 변경 전후 학생·학번·과목 점수·총점·문항 답안/판정, 사유, 처리자와 처리 시각을 보관한다. 동일 시험을 다시 가져와도 이력은 남는다.
- 관리자/최고관리자만 사용한다. 타 학원 학생 연결, 이미 성적이 있는 대상 학생 덮어쓰기, 변경된 화면에서의 오래된 저장은 거부한다. 수기로 변경한 파생 성적의 원본 증명이 일치하지 않으면 정정을 중단한다.
- 외부 평균·문항 정답률은 외부 원본 통계다. 총점이 바뀐 학생의 원본 외부/지역 석차·백분위는 무효화한다. 외부 확정 통계를 변경하려면 수정된 채점 파일을 다시 가져온다.
- 이 기능은 이미 매칭되어 저장된 응시 성적을 대상으로 한다. 원본에서 미매칭되어 저장되지 않은 답안, 미응시 과목 추가, 전체 정답표 변경은 수정 파일 가져오기를 이용한다.
- 재가져오기는 시험 전체 성적을 원본 파일 내용으로 교체한다. 정정 내용을 원본 파일에도 반영해야 하며, 재가져오기 전 기존 정정 이력을 확인한다.
