# 스터디홀 성능·안정성·보안 점검 결과

2026-09-08 / 로컬 코드 수정 및 검증 완료

경찰 RESTART v3.1 규정값과 직렬별 설정을 유지했다. 운영 DB 변경, 마이그레이션, 배포는 수행하지 않았다. 작업 시작 시 저장한 파일 사본을 기준으로 이번 수정과 동시 진행 중인 UI 수정을 구분했다.

## 차단한 문제

- **다른 직렬 좌석 수정:** 좌석 편집 저장이 전달된 좌석 ID만으로 갱신하던 경로에 직렬·자습실 소속 확인을 추가했다. 삭제·배정 해제 등 어떤 쓰기도 하기 전에 검사하며, 최종 UPDATE에도 같은 조건을 적용했다. 경찰/소방 양방향 실패 테스트에서 쓰기 0회를 확인했다.
- **포털 외부 이동 우회:** `/\\외부호스트`, 제어문자가 포함된 경로 등 브라우저가 외부 주소로 해석하는 이동 경로를 거부한다. 파일 형식의 실행 토큰 입력도 거부한다.
- **로그인 제한 우회:** 임의의 IP 전달 헤더를 무조건 신뢰하지 않도록 했다. Vercel에서는 `x-vercel-forwarded-for`, 별도 프록시에서는 명시적인 `TRUST_X_FORWARDED_FOR=true` 설정의 `x-forwarded-for`만 사용하며 실제 IP 형식을 검사한다. 별도 프록시는 해당 헤더를 덮어써야 한다. [Vercel 요청 헤더 기준](https://vercel.com/docs/headers/request-headers#x-vercel-forwarded-for)
- **내부 정보 노출:** 계정·설정·통계 API의 원본 예외 메시지를 공통 오류 응답으로 교체했다. SQL·인증정보·학생정보를 로그에 기록하지 않고 오류 ID·작업명·오류 유형·안전한 코드만 남긴다. DB 초기화 스크립트의 연결문자열 일부 출력도 제거했다.
- **위험한 입력:** 설정 복사 요청의 숫자·배열·잘못된 slug, 숫자가 아닌 조회 주 수, 달력에 없는 시험일을 거부한다.

시크릿 패턴 검색에서 이번 검토 대상 소스에 추가로 확정된 개인키/API 비밀키 리터럴은 없었다. 동적 SQL도 확인했으며, 값 매개변수와 제한된 컬럼/열거값을 사용하는 경로는 유지했다.

## 예외 처리와 정리

- 인증 조회 장애는 허용으로 넘어가지 않고 오류 응답으로 종료한다. 기능 설정 조회 실패도 기능을 허용하지 않는다.
- 로그인·현재 세션 조회·CSV 양식/주간 내보내기의 처리되지 않던 예외를 HTTP 경계에서 처리한다. 실패한 쓰기를 성공으로 반환하지 않는다.
- 휴대폰 현황·학습시간·학습 순위에서 이전 요청과 화면 해제 시 요청을 취소한다. 늦게 도착한 응답이 최신 화면을 덮어쓰지 않도록 확인한다.
- 검색창의 지연 타이머를 화면 해제 시 정리한다. 로그인 제한 정리 타이머는 프로세스 종료를 방해하지 않으며, 각 제한 시간에 맞춰 만료시킨다.
- 시험 D-Day 계산을 기존 주석과 운영 기준인 한국 자정에 맞췄다. UTC 서버와 한국 시간대 서버에서 같은 결과를 확인했다.
- 사용하지 않던 ref, 중복 인덱스 함수, 중간 배열, 활동 유형의 불필요한 단언을 제거했다. 설정 JSON의 `as never`는 실제 Prisma 입력 타입으로 바꿨다.

실행 명령:

```text
pnpm test
pnpm test:integration
pnpm test:all
pnpm typecheck
pnpm lint
```

`test:integration`은 `.local/test-<임의 ID>`에 소스를 복사하고, 운영 환경변수 없이 합성 mock 데이터와 빈 로컬 DB 주소를 사용한다. 기존 작업 폴더의 mock 데이터와 `.next`를 초기화하지 않는다. 검증 서버는 실행 후 종료하며 로그는 해당 임시 폴더에 남긴다. `scripts/smoke-test.mjs` 단독 실행은 기존 초기화 동작이 있으므로 통합 명령으로 실행한다.

## 최종 검증

- 단위·회귀 테스트 **202/202 통과**, 건너뛴 테스트 없음.
- HTTP 통합 테스트 **323/323 통과**.
- 기존 운영 시나리오: 4개 직렬 관리자, 조교·학생, 학생 등록, 좌석 충돌, 수납, 공지, 성적 저장, 소급 상벌점, 휴대폰 출결 연동·일괄 대여 통과.
- `pnpm typecheck`, `pnpm lint`, 미들웨어를 포함한 Next.js 프로덕션 빌드 통과.
- 연산 비교 및 타입/린트 로그: `.local/review-2026-09-08/`.
- 최종 빌드·운영 시나리오·HTTP 로그: `.local/test-f512bca5/integration.log`.
- 추가 수동 브라우저 검증 서버 실행은 자동 승인 검토에서 차단되었으며, 상세 사유는 제공되지 않았다. 이번 검증 결과는 코드·합성 데이터·API·빌드 범위다.

DB 집계/트랜잭션의 분기 및 필터는 대역으로 검증했다. 실제 PostgreSQL 실행 계획, 운영 서버 부하, 운영 Supabase 인증 연동은 이번 테스트 결과에 포함하지 않는다. 로그인 시도 제한은 기존 프로세스 메모리 방식으로 유지했으며, 여러 서버 인스턴스 간 공유 제한을 새로 도입하지 않았다.
