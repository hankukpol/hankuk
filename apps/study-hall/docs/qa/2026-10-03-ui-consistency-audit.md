## 정리 규칙 (운영자 승인 "순서대로 계속 수정", 반영됨 — DESIGN.md 0절)
1. 보조 작업은 외곽 버튼(아이콘+글자, compact). 글자 링크는 표 안 이름·문장 속 이동에만.
2. 데이터 묶음은 `admin-panel`(머리: 제목·부제 + 오른쪽 작업 버튼) → 숫자 격자 → 이름 붙은 행. `admin-notice`는 경고·안내 문장 전용.
3. 요약 숫자는 한 모양(라벨 위, 값 아래, 같은 정렬).
4. 페이지 머리 = 제목 + 설명 1줄 + 오른쪽 주 작업. 설명 문단을 본문 곳곳에 흩지 않는다.
5. 필터는 한 줄 필터 바. 같은 조건을 칩과 선택 상자로 이중으로 두지 않는다.
6. 탐색은 최대 2단(폴더 탭 + 밑줄 탭).
7. 빈 상태·로딩·오류는 한 모양.
