# 아침모의고사 미응시 벌점 면제

후속 구현: [아침시험 교시 연동](2026-09-15-morning-exam-attendance.md)을 켠 학원은 날짜 전체가 아닌 시험 교시 출결로 면제한다. 아래 날짜 단위 처리는 연동을 켜지 않은 기존 학원의 동작이다.

기존 면제 조건을 공용 `isExcusedExamAbsence` 판정으로 정리하고 회귀 검증을 추가했다. 학원별 시작일·시험 요일·휴강일·벌점 규칙 설정은 유지한다.

- 해당 시험일의 출결이 휴무(HOLIDAY), 반휴(HALF_HOLIDAY), 사유결석(EXCUSED)이면 미응시 벌점을 부과하지 않는다.
- 같은 날 승인 또는 사용 처리된 휴가 기록(APPROVED/USED)이 있어도 면제한다. 이 경로는 출결 행이 없어도 적용된다.
- 날짜 단위 면제다. 일부 교시만 반휴/사유결석인 경우도 해당 날짜를 면제하는 기존 동작을 유지한다.
- 관리자/조교가 출결을 저장하거나 관리자가 휴무·반휴 승인/취소를 처리하면 기존 `syncAttendanceDerivedPoints` → `syncExamPoints` 경로에서 재계산한다.
- 사후 승인 시 해당 자동 미응시 벌점만 취소한다. 수동 벌점, 타 학원 기록은 보존한다. 승인 취소 후 다른 면제 사유가 없으면 학원의 기존 규칙으로 다시 계산한다.
- 결석 상태에 사유 메모만 입력하거나 휴가가 대기/거절 상태인 경우는 승인된 면제가 아니다.

검증: 세 출결 상태의 선면제/사후 취소/중복 실행, 출결 없는 휴가 승인·사용/취소, 다른 날짜, 단순 사유 메모, 수동 점수와 타 학원 보존. `tests/unit/exam-point-services.test.ts` 9개 통과. 실제 운영 DB 변경·배포는 하지 않았다.
