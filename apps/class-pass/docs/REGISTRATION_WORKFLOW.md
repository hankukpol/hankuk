# 수강등록 모달 개선 (2026-09-05)

## 적용 내용

- 이름·연락처·생년월일을 검사하고 해당 입력란 아래에 한글 오류를 표시한다. 학번은 기존 API 정책대로 선택 입력이다.
- 단일/복수 강좌 모두 강좌별 정가·할인·사유가 표시와 저장의 공통 기준이다. 중복 할인 입력을 제거했다.
- 정가를 직접 수정하는 기존 기능은 유지한다. 할인은 해당 강좌 정가를 초과할 수 없다.
- 강좌 추가·삭제·재추가 시 금액 초안, 카드/현금 선택, 수납일시, 공통 메모를 보존한다.
- 각 강좌에 무료 수강과 면제 사유를 지정할 수 있다. 전체 강좌 무료는 일괄 적용이며 해제하면 기존 개별 초안으로 돌아온다.
- 무료로 전환해도 유료 할인 초안은 지우지 않는다. 할인과 면제를 동시에 저장하지는 않는다.
- 무료와 유료 강좌를 함께 등록할 수 있다. 미수납 등록 시 유료 강좌에는 청구만, 무료 강좌에는 0원 면제 기록을 남긴다.
- 정가 자체가 0원인 강좌는 면제 사유 없이 등록할 수 있으며 가짜 카드/현금 수납을 만들지 않는다.
- 등록 하단에 강좌 수, 유료/무료·0원 개수, 납부 금액, 입력 수납액을 고정 표시한다.
- 저장 중 전체 입력을 잠그고 중복 제출을 차단한다. 실패 시 입력을 보존한다.
- 한 번에 최대 8강좌까지 추가할 수 있다.

## 직원 사용 순서

1. 기존 학생을 찾거나 인적 사항을 입력한다.
2. 추가 강좌를 선택하고, 각 강좌의 정가·할인 또는 무료 수강 여부를 확인한다.
3. 무료 강좌에는 면제 사유를 입력한다. 모두 무료라면 일괄 무료와 공통 사유를 사용한다.
4. 수납일시와 실제 받은 결제수단별 금액을 입력한다.
5. 하단 합계를 확인한 뒤 `등록 + 수납 저장`, `수납 없이 등록`, `무료 수강 등록` 중 상황에 맞는 동작을 선택한다.

카드 승인이나 계좌 이체를 실행하는 화면이 아니라 실제 받은 금액의 기록 화면이다.
포인트는 무료 사유가 아니라 결제수단으로 입력한다.
결제수단이 하나이면 강좌 금액에 맞춰 수납액을 갱신한다. 여러 수단으로 나눈 금액은 임의로 재분배하지 않는다.
강좌를 변경해 분할 수납 합계가 달라지면 저장 전에 직접 확인·조정한다.

## 수납 실수 방지와 입력 보호 추가 개선

- `수납 없이 등록`은 확인창을 거친다. 유료 강좌 전액이 미수납으로 남고 화면에 입력한 수납액은 저장되지 않는다고 안내한다. 무료 강좌의 면제 기록은 유지한다.
- 확인창의 `돌아가기`는 모든 초안을 보존한다. `수납 없이 등록하기`를 선택해야 실제 저장 요청을 보낸다.
- 하단에 `50,000원 부족`, `20,000원 초과`, `수납 금액 일치`를 실시간 표시한다. 부족·초과 상태로 수납 저장은 할 수 없다.
- 등록 화면의 수납 입력을 자동으로 잘라내거나 다른 결제수단 금액을 줄이지 않는다. 할인 사유 수정만으로 입력한 수납액이 초기화되지 않는다. 다른 수납·환불 화면의 기존 자동 조정은 유지한다.
- 입력을 변경한 뒤 X·취소·Escape·배경 클릭·스와이프로 닫으려 하면 확인한다. `계속 작성`은 초안을 유지하고 `입력 버리고 닫기`만 닫는다. 입력하지 않았거나 원래 값으로 되돌린 경우에는 불필요한 확인을 띄우지 않는다.
- 강좌별 `접기`로 이름·유료/무료 여부·적용 금액만 요약한다. `펼치기`로 돌아와도 값이 유지된다. 오류가 있는 강좌는 펼쳐지고, 오류를 수정하는 도중 다시 접히지 않는다.
- 이 보호는 모달 내부 닫기 동작에 적용한다. 브라우저 새로고침·탭 닫기·개발 중 코드 자동 갱신까지 초안을 영구 보관하는 기능은 아니다.

추가 개선 검증: 관리자·등록·결제 관련 139개 테스트, TypeScript, build, 범위 지정 diff 검사 통과.
390/768/1280px 로컬 브라우저에서 부족·초과 안내, 강좌 요약 접기, 미수납 확인/취소,
미저장 확인/복귀/폐기를 검증했다. 확인창에서 실제 등록 저장은 실행하지 않았다.

## API / 배포 범위

- 기존 `/api/enrollments`와 `/api/enrollments/batch` 및 기존 원자적 등록 RPC를 사용한다.
- 묶음 API의 `exemptionPaidAt`은 선택적 ISO 날짜/시간 필드다. 유료 결제 배열이 비어 있는 경우에도 무료 기록의 수납일시를 보존한다.
- 기존 호출은 결제 내역의 날짜, 그마저 없으면 기존 DB 기본 시각을 사용하는 동작과 호환된다.
- 기존 인증·지점 구분·교재 검증·수강종료 재등록 제한은 변경하지 않았다.
- 이번 변경에서 새 SQL 마이그레이션은 만들거나 적용하지 않았다. 다른 작업의 기존 미배포 마이그레이션 상태를 의미하지 않는다.
- Git 커밋/푸시, Vercel 배포, 운영 DB 변경은 수행하지 않았다.

- 로컬 브라우저 390/768/1280px 확인. 390px에서 입력·오류·하단 버튼의 가로 넘침 없음.
