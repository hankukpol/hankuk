# 성적 분석 개선안 로컬 미리보기

기존 성적 분석을 보존하고 별도 경로에 구현한 검토용 화면이다. 운영 데이터 연결, 기존 화면 교체, 커밋·푸시·배포는 포함하지 않는다.

## 메가공무원 샘플 구성 반영

2026-09-16 사용자 피드백에 따라 관리자 분석 항목 7탭을 `채점결과 / 회차별 누적 성적` 2탭으로 재구성했다. 브라우저 댓글 7건 반영 후 채점결과는 과목별 레이더와 수치 표 → 점수 4칸 비교 → 순위·목표 표 → 복습 진단 표 → 문항별 정오·선택률 표 순서다. 문항 행의 반복 날짜를 제거했고 여러 날짜 조회에서만 날짜별 묶음 제목을 표시한다. 정답률은 시험 원자료와 학원 응시자 기준을 이름과 설명으로 구분한다. 누적 탭에는 추이 그래프와 회차별 비교표, 입력 성적 기록이 함께 나온다. 학생은 기존 원칙대로 내용을 숨기지 않는 바로가기를 유지한다.

- 데스크톱 선택률은 별도 펼침 없이 열로 표시하고, 모바일에서는 문항별 펼침으로 확인한다.
- 현재 전체 분석인지 개인 성적표인지 제목과 학생 선택 안내로 구분한다. 전체 분석에는 개인 정오를 표시하지 않는다.
- 레이더는 저장된 과목별 만점 대비 득점률이다. 샘플의 단원별 정답률과는 다르다. 문항별 단원 정보가 없으므로 단원 분석은 생성하지 않는다. 비교 가능한 과목이 3개 미만이거나 비교값이 누락되면 그래프 대신 안내를 표시한다.
- 계산 서비스·인증·기존 성적 페이지는 변경하지 않았다. 수정 후 브라우저 증거는 `.superloopy/evidence/frontend/2026-09-16-exam-preview-reference/`에 별도 보관한다.

## 실행

앱 폴더에서 `node scripts/start-exam-preview.mjs`를 실행한다. 전용 런타임을 `.local/exam-preview/runtime-*/`에 만들고 사용 가능한 로컬 포트를 출력한다. 기존 서버를 종료하지 않는다. 운영 `.env` 파일은 복사하지 않는다.

- 관리자 로그인: `/login`, `admin-police@mock.local`, 비밀번호는 비어 있지 않은 테스트 문자열. 소방은 `admin-fire@mock.local`.
- 학생 로그인: `/police/student/login`, 수험번호 `98001`, 이름 `테스트 김서준`.
- 관리자 전체: `/police/admin/exams/preview`
- 관리자 개인: `/police/admin/exams/preview/students/preview-police-s0`
- 학생 개인: `/police/student/exams/preview`
- 날짜·시험 ID는 런타임 `review-state/manifest.json`에 기록한다. 아침 시험은 기본 오늘이며 `이번 달`로 여러 회차를 볼 수 있다.
- 현재 실행 주소·PID·저장소는 `.local/exam-preview/runtime.json`에 기록한다. 종료 시 이 파일의 PID에 해당하는 본 작업 서버만 종료한다.

미리보기는 `EXAM_ANALYSIS_PREVIEW=true`와 `MOCK_MODE=true`가 모두 필요하다. 기본 비활성이고 실제 DB 연결에서는 열리지 않는다. 테스트 로그인은 기존 MOCK_MODE 인증을 그대로 사용하며 운영 인증을 변경하지 않았다.

## 구현 경계

**현재 개인 리포트 구성과 오늘 요청의 최종 점검은 [2026-09-16 요청 재점검](exam-analysis-request-audit-2026-09-16.md)이 기준이다.** 아래 날짜별 기록은 변경 이력이며, 이후 요청으로 제거된 메뉴/이름/배치도 포함한다.

신규 코드는 `components/exams/preview`, `lib/exam-preview`, 전용 페이지·API에만 추가했다. 기존 페이지·분석 서비스·API·스타일·스키마를 수정하지 않는다. 인쇄는 기존 출력 규격을 바탕으로 별도 컴포넌트에 구현했다. 기존 공용 탭·레이아웃·디자인 토큰·인쇄 문서 변환 함수는 수정 없이 재사용한다.

전용 조회 API는 `/api/[division]/exam-analysis-preview/regular`, `/morning`이다. `examTypeId`가 필수이며 관리자 전체는 studentId 없이, 개인은 studentId를 전달한다. 정기는 examDate, 아침은 from/to를 사용한다. 기존 권한 검사와 학원 기능 설정 검사를 통과해야 한다. 응답은 private/no-store다.

기존 분석 결과를 재사용하고 원자료로 비교 행·선택률·배점·응답 인원을 보완한다. 현재 전용 데이터 어댑터는 분리한 로컬 MOCK 저장소를 읽는다. 운영 적용 시에는 별도 승인 후 같은 계약의 DB 조회 어댑터와 실자료 검증이 필요하며, 단순 경로 교체만으로 운영 완료로 간주하지 않는다.

## 계산·표현 기준

- 과목별 만점은 저장된 문항 배점 합계다. 현재 설정의 배점으로 과거 시험을 재계산하지 않는다.
- 상위 10%/30%는 원자료의 총점 순 집단을 유지한다. 과목별로 재선정하지 않으며 불완전 집계는 비운다.
- 개인 비교 평균은 본인이 응시했고 비교값도 있는 회차만 사용한다. 대응 회차 수를 함께 표시한다. 회차 만점이 다르면 통합 원점수 평균을 숨기고 차트에 득점률을 사용한다.
- 미응시는 0점이 아니다. 외부 평균은 남는다. 무응답 행과 응답 행 자체가 없는 경우를 구분한다.
- 정오는 가져온 채점값을 사용한다. 응시하지 않은 선택과목의 문항을 개인 오답으로 포함하지 않는다.
- 복습 대상 배점은 확인된 오답 배점 합계이며 예상 상승 점수가 아니다.
- 문항별 내부 정답률 분모는 해당 과목 응시자의 실제 응답 행 수다. 외부−내부 차이는 %p다.
- 시험 범위는 등록된 설명일 뿐 세부 단원 숙련도가 아니다. 풀이시간·오답 원인·합격 확률을 만들지 않는다.
- 상담 참고는 관리자 응답에만 포함한다. 출결·휴대폰 교시별 기록 건수로 표시하고 일수·학습 시간·인과관계로 해석하지 않는다. 정기는 해당 월 1일~시험일, 아침은 선택 기간이다.
- 문항 상세 인쇄는 선택 과목 기준이다. 전체 인쇄는 모든 분석 탭과 선택 과목 전체 문항·선택률, 비교를 위한 전체 과목 요약·성적 기록을 담는다. 요약 인쇄는 선택 과목 점수 요약과 복습 진단을 담는다. 상담 자료는 둘 다 제외한다. 화면 필터와 펼침 상태는 출력 준비 후 복원한다.
