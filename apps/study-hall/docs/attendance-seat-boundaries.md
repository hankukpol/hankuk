# 좌석 배정과 교시별 출결의 역할

2026-09-14 사용자 확정 기준.

| 화면 | 업무 | 출결 표시·저장 |
| --- | --- | --- |
| 관리자 좌석현황 `/admin/seats` | 배정 학생·공석 확인, 공석 배정, 기존 학생 이동 | 출결 조회·배지·출석률·출결 편집 없음 |
| 관리자 출석관리 `/admin/attendance` 좌석 탭 | 선택 날짜·교시 출결 확인 및 입력 | 선택한 교시만 표시하고 학생 편집창도 해당 교시만 저장 |
| 조교 출석체크 `/assistant/check` 좌석 탭 | 현장 출결 확인 및 입력 | 선택 교시 기준. 다른 교시 결과를 대표 상태로 합산하지 않음 |

- 좌석현황의 배정 인원은 실제 배정 학생을 센다. 휴가 중인 학생의 좌석도 배정된 좌석이다.
- 관리자 좌석현황에서 공석을 누르고 학생을 선택하면 배정한다. 기존 좌석이 있으면 이동한다. 좌석 배치 구조 편집은 설정의 좌석 배치에서 한다.
- 출석관리 좌석에서 저장해도 다른 교시에 작성한 미저장 입력은 저장하거나 폐기하지 않는다.
- 수업은 저장 형식 `EXCUSED`와 `수업` 또는 `수업: 수업명` 사유를 함께 판정한다. 수업은 출석·개근에 포함하고 일반 사유결석은 출석률의 분모·분자와 자동 결석벌점에서 제외한다.
- 학생 달력·상세 이력·휴대폰 화면도 같은 상태와 사유로 수업·사유결석을 구분한다. 기존 대여폰 반납은 수업으로 출결이 바뀌어도 가능하다.
- 조교는 자신의 직렬 좌석도를 조회할 수 있다. 좌석 배정·이동·레이아웃 변경 API는 관리자 전용이다.
- 저장 직후의 통계·개인 출결·좌석 조회는 `private, no-store`를 사용한다.

## 모바일 실측 보완

390px 화면에서 출석 좌석의 기존 최소 폭 88px 안에 좌석번호와 미처리 배지가 함께 놓이면 `A-02`가 세로로 갈라졌다. 휴대폰 좌석도와 동일한 최소 폭 140px, 좌석번호 줄바꿈 금지, 상태 배지 행 줄바꿈을 적용한다. 실제 좌석 위치를 보존하기 위해 좌석도 안에서만 가로 스크롤한다. 문서 전체의 가로 넘침은 허용하지 않는다. 기존 글자 크기·상태 토큰·터치 높이 규격은 유지한다.

## 검증 범위

선택 교시 표시·부분 저장·실패 재시도, 수업과 사유결석 집계, 학생·휴대폰 표시, 조교 조회/관리자 배정 권한은 회귀 및 HTTP 통합 검사 대상으로 유지한다. 로컬 목업에서 배정·출결 저장을 실행하고 운영 검증은 읽기 전용으로 한다. 운영 데이터 보정이나 스키마 변경은 이 코드 변경에 포함하지 않는다.
