# 학원별 성적 자동 상벌점

> 성적 순위 상점은 월별 지급이다. 회차별 지급 구현은 [월별 지급 정정](2026-09-14-monthly-exam-merits.md)에서 수정했다.

## 설정

관리자 → 설정 → 운영 규칙 → 성적·월말 자동 상벌점.

- 학원마다 별도의 시작일, 요일, 휴강일, 규칙을 저장한다. 다른 학원 규칙 ID는 연결할 수 없다.
- 아침모의고사는 달력에서 지정한 시작일 이후, 월~금 중 체크한 요일만 계산한다. 휴강일은 제외한다. 시작일 미지정 시 자동 부여하지 않는다.
- 정기모의고사·휴일권 자동 월 마감에는 별도의 적용일을 사용한다.
- 변경한 설정은 이번 달·지난달 기록에 반영한다. 더 이전 기록은 해당 시험을 다시 가져올 때 적용한다.
- 신규 학원은 자동화가 꺼져 있다. 경찰 운영 설정만 활성화하며, 아침 시작일·요일은 운영자가 직접 지정한다.

## 계산 및 정정

- 가져오기 확정·교체·삭제와 성적 상벌점 갱신을 한 트랜잭션에서 처리한다. 동일 기록은 ID를 유지하며 중복 부여하지 않는다.
- 점수는 학원 규칙에서 읽는다. 관리반의 재원 학생 중 실제 매칭된 응시자만으로 동점 공동 순위를 계산한다. 부분 점수·외부 응시자 순위는 상점 순위에서 제외한다.
- 아침 미응시 벌점은 하루 한 번, 정기 미응시 벌점은 회차별로 부여한다. 아침 미응시와 1교시 출결은 별개의 의무다.
- 해당 날짜의 수업·사유 인정·휴무/반휴·승인 일정은 미응시 벌점에서 제외한다. 출결/승인 변경 시 성적 벌점도 다시 계산한다.
- 월 개근은 닫힌 달의 실제 예정 요일에 모두 응시한 경우만 지급한다. 첫 달은 관리자가 정한 시작일부터 계산하며, 파일이 없는 예정일은 개근으로 간주하지 않는다.
- 기존 일일 마감 작업에서 이번 달·지난달 성적을 재확인하고, 허용된 학원만 지난달 휴일권 미사용 상점을 정산한다. 휴학생·퇴실생에게 새 자동 상벌점을 부여하지 않는다. 기존 이력은 보존한다.
- 기존 `기본이론 수업 수강` 등 수업 사유도 출석으로 인식한다. 미참여·불참·없음 등 부정 표현은 제외하고, 편집 시 `수업: 강좌명`으로 저장한다.

## 배포

마이그레이션 `20260914200000_exam_point_automation`은 학원 설정에 nullable JSON 열 하나를 추가한다. 다른 학원의 설정과 기록은 변경하지 않는다.

운영의 아침모의고사 시작일과 요일은 임의로 지정하지 않는다. 관리자 달력·체크박스로 지정하고 저장해야 활성화된다.

## 검증

단위/회귀 754개, 실제 PostgreSQL의 학원별 배점·달력·동시 실행·원자적 롤백·수업 제외, HTTP 설정 권한/타 학원 접근/재가져오기 멱등성을 검증한다. 모바일 390px에서 날짜 입력·저장·재접속을 확인했으며, 390/768/1280px에서 새 설정 영역의 가로 넘침은 없다. 날짜/저장 컨트롤은 44px, 글자는 15px이다.
