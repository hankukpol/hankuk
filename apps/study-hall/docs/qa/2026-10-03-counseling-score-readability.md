## 면담에 이미 충분한 것
- 과목별 내 점수와 같은 시험 평균, 주간 성적표, 응시 횟수, 시험 응시자 중·우리 학원 중 순위, 날짜별 틀린 문항 번호, 많이 맞힌 문제 중 내 오답(우선 복습), 관리자 개인 분석 아래 출결·휴대폰 상담 참고.
- 관리자 전체 분석의 학생별 취약점 표(과락선 미만 / 점수 하락 / 학원 평균보다 낮음 필터)로 면담 순서를 정할 수 있다.

## 발견 (화면 실측)
1. 한 줄 결론이 요약 탭의 접힌 영역(`점수·응시·주간 성적 자세히 보기`) 안에 있다. 처음 화면에는 과목 표만 보인다. 9/25 운영자 요청(한 줄 결론 필요)과 어긋난다.
2. 요약 표의 상태가 대부분 `판단 보류`다. 기준은 학원 설정 `morning.movingAverageSessions`(기본 4회)·응시율 70%. 운영은 9/8~10/2 과목별 4회(경찰학 2회)라 경찰학은 전원, 한 번이라도 빠진 학생은 다른 과목도 보류가 된다. 예시에서 평균보다 5점 높은데도 `판단 보류`만 보이고, 이유(`학원 분석 기준에 필요한 기록 부족`)는 눌러야 보인다.
3. 숫자 표기: `시험 응시자 평균 대비 2.7점`에 +/- 부호가 없다. 같은 화면의 결론은 `-3.3점`이라 서로 모순처럼 읽힌다. `이번 주 석차 12위`에 분모(명)가 없다. 석차 탭 주차가 `2026년 40주`(ISO 주번호)이고 다른 곳은 `9/28 주`. 주간표의 빈 점수가 `점수 없음`/`결시`로 섞인다.
4. 학생 성적 화면은 주소 인자가 없으면 정기 모의고사를 먼저 연다(`lib/exam-preview/selection.ts`). 운영 정기 성적은 0건이라 학생이 처음 보는 화면이 빈 화면이다. 학생 화면의 접힘 제목이 `시험·학생 조회 조건`이다(학생에게 `학생` 선택은 없다).
5. 취약점 탭이 모바일에서 약 4,300px(요약 2,100 / 석차 1,470 / 추이 2,990 / 문항 1,970). 기본 과목이 가장 약한 과목이 아니라 최근에 친 과목이다. `진도별 취약점과 다음 학습`은 카드당 9칸(채점 문항·비교 문항·%p·후속 정기시험 등)이고, 운영은 세부단원·문항 연결이 0건이라 이 영역은 판단 자료가 없다.
6. 인쇄 버튼이 `선택 과목 A4 인쇄 / PDF 저장`, `선택 과목 학습 요약 인쇄` 두 개이고, 요약 탭에서 무엇이 `선택 과목`인지 화면에 없다. 면담용 1장(성적 요약 + 우선 복습 문항 + 출결 + 과제·다음 점검일 칸)은 없다.
7. 면담 기록 화면(`InterviewContextPanel`)에 성적이 없고 개인 성적 분석으로 가는 링크도 없다. 학생 상세에서도 없다. 개인 분석은 시험 성적 → 전체 분석 → 아침 → 학생 이름으로만 들어간다.

## 제안 순서 (운영자 승인 전, 미구현)
- A(다음 주 전): 결론 문장을 요약 맨 위로, `판단 보류` 대신 실제 비교(평균보다 N점 높음/낮음) + `시험 N회라 참고용` 꼬리표, 부호·분모·주 표기 통일, 학생 화면 기본을 성적 있는 시험으로, 면담 기록·학생 상세에 `성적 분석 열기` 링크.

- C: 취약점 탭 정리(기본 과목 = 평균보다 가장 낮은 과목, 세부단원 연결이 없으면 진도별 학습 영역 숨김, 용어 정리).
