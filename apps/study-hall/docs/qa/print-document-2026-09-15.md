# 성적 인쇄 문서형 레이아웃 검증

## 변경 범위

- 인쇄 복사본에만 적용: 성적 요약 지표를 4열 항목/값 표로, 복습 문항을 2열 표로 변환.
- 보고서 제목을 문서 맨 위에 배치하고 본문을 단일 열로 연결.
- 화면 미리보기는 문서 너비로 제한하고 모바일 여백 적용. A4 세로 12mm 여백, 반복 표 머리글 및 행 분할 방지는 유지.
- 성적 계산, 학원별 설정, API, 운영 기록 및 원본 페이지 구조는 변경하지 않음.
- 전체 인쇄와 학습 진단 인쇄를 모두 지원. 한 장에 강제 축소하지 않음.

## 검증 결과

| 검증 | 결과 |
| --- | --- |
| TypeScript | 통과 |
| ESLint | 경고 및 오류 없음 |
| 인쇄 변환 및 기존 성적 UI 테스트 | 21개 통과 |
| 정기/아침 × 전체/학습 진단 × 390/768/1280px | 12개 조합 통과 |
| 가로 넘침, 표의 화면 경계 초과, 남아 있는 숨김 패널 | 0건 |
| 인쇄 종료 후 원본 탭 상태 | 유지 |
| 팝업 런타임 오류, 이미지 디코딩 오류 | 0건 |
| 인쇄 버튼 호출 | 확인 |
| A4 PDF | 4개 생성, 정기 전체 8쪽 / 아침 전체 3쪽 |

현재 로컬 모의 데이터에서 정기 전체는 표 15개/행 157개/차트 2개, 아침 전체는 표 9개/행 43개를 확인했다. PDF를 PNG로 렌더링해 제목, 11열 비교표, 차트 및 이어지는 채점표를 확인했다. 로그인 이후 업무 API 쓰기는 차단했다.
