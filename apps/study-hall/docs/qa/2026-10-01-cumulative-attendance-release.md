# 누적시험 출석 가져오기 수정·배포 검증 (2026-10-01)

## 목적과 동작

누적시험은 성적/석차/문항 분석을 저장하지 않고 응시 여부만 출석에 반영한다.
성적 자동화가 없는 요일에도 학원 관리규정에서 아침 교시를 관리하는 날이면 명시적 파일 가져오기를 허용한다. 시작일/휴강일/적용일/연동 여부/학원 소유권 검사는 유지한다.

- 빈 수험번호 답안은 건수를 안내하고 제외. 다른 학생으로 추정하지 않는다.
- 식별자 오류, 중복, 손상된 3행 블록은 계속 거부한다.
- 미리보기 후 선택한 학생만 저장. 파일 누락 학생은 자동 무단결석 처리하지 않는다.
- 기존 응시/사유/휴무를 보호하고 미리보기 이후 원장 변경은 재확인을 요구한다.
- 설정이나 DB 스키마 변경은 필요 없다.

## 검증

- 자동 테스트 955/955 통과. 학생 상세 렌더 테스트의 날짜를 fixture와 같은 9월로 고정해 월 변경에 따른 실패를 제거했다.
- 기존 성적 분석 화면의 미사용 Comparison 타입 import를 제거해 lint 차단 원인을 해결했다.
- 격리된 production 빌드(컴파일·lint·타입 검사 포함)와 HTTP 통합 검증 1/1 통과. 목요일(관리 요일 포함/성적 자동화 요일 제외), 빈 식별번호, 인증/타 학원/외부 origin 거부, 사유 보호, 충돌, 저장 후 조회, 성적 및 타 학원 보존을 확인했다.
- 실제 운영 파일/개인정보/백업은 Git 제외 .local에만 보관한다. 운영 재검증은 이미 반영된 오늘 출석을 재저장하지 않고 파일 미리보기로 수행한다.

## 배포 범위와 상태

사용자의 이번 요청으로 커밋/푸시/운영 배포 승인됨. main의 기존 성적 분석 관련 커밋 3개를 포함한 현재 소스가 배포 기준이며, 다른 미커밋 문서/출결 테스트/인접 앱 변경은 이번 커밋에서 제외한다.
배포 ID와 운영 확인 결과는 완료 후 추가한다.
