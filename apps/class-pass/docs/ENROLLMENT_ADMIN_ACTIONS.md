# 관리자 수강 관리

## 사용 위치

수강생 명단의 `더보기` 메뉴:

- **수강 재개**: 수강종료·환불 상태를 수강중으로 전환. 기존 이력을 보존하며 결제를 자동 생성하지 않는다. 재개 후 `수납·환불 → 수납 추가`로 새 결제를 기록한다.
- **명단 숨김**: 기본 명단에서 제외한다. 수강중인 등록은 함께 종료한다.
- **명단 복원**: `숨긴 명단` 필터에서 실행한다. 명단에만 복원하며, 수강 재개는 별도 작업이다.
- **오등록 완전 삭제**: 현재 강좌 등록과 잘못 입력한 결제만 제거한다. 학생 기본정보와 다른 강좌 등록은 보존한다.

완전 삭제는 되돌릴 수 없다. 환불 또는 실제 카드 취소를 실행하지 않는다. 학생 확인 문구, 오등록 확인 체크, 처리 사유가 모두 필요하다. 실제 이용·환불·정산 또는 다른 연결 이력이 있으면 차단한다. 삭제 사유·처리자·대상 등록 ID·금액 합계는 별도 감사 기록으로 남는다.

## 배포 순서

1. 계정 및 기존 운영 프로젝트 `pbonwjwbtqyrfrxqdwlu`를 확인한다.
2. 원격 적용 여부와 스키마를 확인하고 새 마이그레이션 `20260908073124_enrollment_admin_lifecycle.sql`만 적용한다. 다른 미적용 파일을 함께 push하지 않는다.
3. DB 함수 권한과 컬럼을 읽기 전용으로 확인한 후 기존 Class-pass 프로젝트에 앱을 배포한다.
4. 운영에서 읽기 전용으로 메뉴·미리보기·미입력 차단을 확인한다. 운영 학생을 시험 삼아 삭제하지 않는다.

이 변경은 `archived_at` 컬럼을 조회하므로 **DB 적용 전에 앱을 배포하면 안 된다**.
