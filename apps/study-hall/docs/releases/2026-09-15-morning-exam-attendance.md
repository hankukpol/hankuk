# 아침모의고사 교시와 성적 연동

## 관리자 설정

1. 설정 > 교시 설정에서 아침모의고사 교시를 활성화한다.
2. 설정 > 운영 규칙 > 관리규정·휴대폰 > 교시·출결에서 아침모의고사 교시를 선택하고 '성적 등록 시 아침시험 자동 출석'을 켠다. 기존 설정 미리보기·적용일·이력 흐름으로 저장한다.
3. 시험 상벌점 설정에서 시작일과 시험 요일, 미응시 벌점 규칙을 지정한다. 경찰 운영의 요청값은 -1점이며 공통 코드에 점수를 고정하지 않는다.

## 처리

- 가져온 채점 결과 또는 직접 입력한 유효 성적(0점 포함)이 연결된 학생의 빈 시험 교시를 출석으로 기록한다.
- 수동 출결·휴무·반휴·사유결석을 덮어쓰지 않는다. 시험 교시의 사유결석을 저장하면 미응시 벌점에서 제외된다.
- 일반 교시 결석·지각·전체 결석 계산에서 자동 연동 시험 교시를 제외한다. 미응시는 기존 시험 가져오기 기준으로 해당 학원의 시험 미응시 규칙만 적용한다.
- 시험 교시를 포함하는 휴무·반휴 승인만 면제한다. 다른 교시의 사유결석이나 단순 메모는 면제 근거가 아니다. 기존 반휴는 설정된 오전 관리교시 개수로 정하며, 그 범위에 있는 시험 교시도 승인 출결에 포함한다.
- 성적 정정·삭제는 자동 출석만 회수한다. 관리자가 수정한 출결은 자동 소유권을 해제하여 보존한다. 휴가 승인/취소 스냅샷도 소유권을 보존한다.
- 자동 출석은 실제 도착 시각을 추정하지 않으며 checkInTime을 생성하지 않는다.
- 자동 연동을 켜지 않은 학원의 기존 동작은 유지한다. 직접 점수 입력만으로 미응시자 전체 명단을 확정하지 않는다.

## 운영 반영

새 nullable 필드 `attendance.exam_auto_source`용 마이그레이션 `20260915020000_exam_attendance`가 필요하다. 기존 출결 데이터는 수정하지 않는다. 코드 배포 및 경찰 학원의 교시 활성화·연동 설정 저장은 사용자 승인 후 별도 진행한다.
