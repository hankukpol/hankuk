# 성적 분석과 다음 학습 연결 구현

범위: 현재 수정 중인 로컬 성적 분석 미리보기. 기존 운영 성적 페이지와 운영 DB, 성적 순위 상점 및 벌점 정책은 변경하지 않았다. 아래 기능은 화면 예시만이 아니라 인증된 API로 저장·조회한다. 로컬 학습 저장소는 성적 원본과 분리된 JSON 파일이며, 운영 DB 마이그레이션·배포는 이 작업의 범위에 포함하지 않는다.

## 사용 경로

1. 관리자 `성적 분석 미리보기 → 진도·학습 분석 설정`.
2. **과목·진도:** 같은 과목의 정기·아침 시험 과목을 연결하고 표준 대단원/세부 진도를 등록한다. 이름이 같다는 이유로 자동 연결하지 않는다.
3. **문항 연결:** 시험일·과목과 문항을 선택하고 세부 진도를 지정한다. 변경 전/후 내용을 확인하고 저장한다.
4. **분석 기준:** 최소 문항/회차, 평균보다 부족한 차이, 반복 오답 기준, 선택 시간 기록과 제한 시간을 적용일과 함께 저장한다. 변경 이력은 보존한다.
5. 개인 성적표의 **성적·진도 요약**에서 다음 학습을 확인한다. **오답·문항 분석**에서 현재 분류의 문항을 선택해 복습을 예약하고, 시험지를 다시 푼 뒤 답을 기록한다.
6. 같은 문제의 재풀이 결과와 후속 정기시험의 다른 문항 결과는 별도로 확인한다.

## 계산과 데이터 경계

- 전체 총점 평균은 검증된 총점 분포에서 계산한다. 과목 평균 합산으로 총점 평균을 만들지 않는다. 서로 다른 만점은 같은 원점수 증가량으로 비교하지 않는다.
- 석차는 경쟁 순위(1, 2, 2, 4)다. 상위 비율은 석차/해당 집단 인원이며 합격 확률이 아니다. 목표선은 현재 등록 목표이며 과거 목표의 이력을 추정하지 않는다.
- 내 오답에는 제출 답안에서 답을 비운 문항도 포함한다. 응시 또는 채점 기록 자체가 없는 문항은 오답으로 생성하지 않는다.
- 진도별 상대 정답률은 같은 문항에 대응한 내 결과와 가져온 전체 정답률의 평균이다. 서로 다른 시험 집단의 인원을 합쳐 누적 응시 인원으로 표시하지 않는다.
- 가져온 자료에 **문항별 외부 분석 인원이 없어** 그 값은 제공되지 않았다고 명시한다. 과목 응시 인원을 문항별 인원으로 바꾸어 표시하지 않는다. 학원 문항 응답 인원은 실제 채점 응답 수다.
- 복습 상태는 현재까지의 이력, 후속 시험 적용은 조회 종료일까지의 기록이다. 시험 날짜만 있으므로 같은 날 재풀이와 시험의 선후관계는 추정하지 않고 다음 날 이후 시험만 연결한다. 정기시험 이전의 마지막 재풀이 결과가 정답인 경우만 인정한다.
- 새 단원 연결은 원본 점수나 답안을 바꾸지 않는다. 재풀이로 원래 시험 점수가 올라가지 않는다. 비교 차이나 재풀이 개선을 난이도가 보정된 실력 또는 인과 효과라고 표시하지 않는다.
- 신규 학원의 설정이 없으면 취약 판정을 하지 않으며 시간 입력은 기본 비활성이다. 새 자동 벌점·상점은 없다.

## 저장·권한

- `MOCK_MODE=true`, `EXAM_ANALYSIS_PREVIEW=true`인 미리보기에서만 제공한다.
- `MOCK_DB_DIR/learning/<학원 ID의 SHA256>.json`에 학원별로 독립 저장한다. 파일 잠금, 임시 파일 교체, 버전 충돌(409), 요청 ID 재전송 중복 방지를 적용했다.
- 관리자: 본인 학원의 진도·정책·예정과 학생 학습 기록. 학생: 본인 학습 기록만. 학원/과목/문항 연결 및 학생 소유권은 서버에서 재검증한다.
- 원래 성적 파일은 유지한다. 복습·시간 기록, 기준 버전, 변경 이력은 추가 방식으로 남긴다. 정책은 적용일을 기준으로 선택한다.
- 운영 적용 시에는 이 계약을 운영용 영속 저장소와 연결하고 백업·마이그레이션·운영 권한을 별도로 검증해야 한다. 이 문서는 운영 배포 증거가 아니다.

## 검증용 자료

- 기존 `preview-*-regular`/아침 시험은 보존하고 `preview-*-monthly`를 추가했다. 2026년 4~9월 각 16일, 회당 100문항이다. 추가 전 로컬 파일 백업을 남겼다.
- 실제 배점을 질문했으나 응답 전이므로 경찰 검증 프로필은 **헌법20/형사법40/경찰학40, 문항당2.5점(250점)**이라는 명시적 합성 가정이다. 확정 운영 규칙이라고 간주하지 않는다.
- 다른 학원 검증 프로필은 **30/35/35문항, 문항당1점(100점)**이며 최소 표본·차이·시간 활성화도 다르다. 경찰 규칙을 다른 학원의 기본값으로 강제하지 않았다.
- 표준 진도 이름은 ‘기본 원리/사례 적용/심화 정리’라는 합성 검증 자료다. 실제 학원 진도 코드를 가장한 자료가 아니다.
- 재현: `node scripts/start-exam-preview.mjs`. 이 실행은 새 분리 환경에서 기본 자료와 추가 학습 자료를 만든다. `exam-learning.ts`를 다시 실행해도 기존 학습 설정·복습 이력은 덮어쓰지 않는다.

## 검증 증거

`.superloopy/evidence/frontend/2026-09-16-learning-loop/`에 단위 테스트, Chrome 기능 검증, 390/768/1280/1874 화면, 학생 모바일 화면, A4 PDF, 빌드·정적 검사 및 성능 측정 결과를 기록한다. 로컬 결과이며 실제 운영 데이터 또는 물리 프린터 검증과 구분한다.


### 최종 기능 결과

- 단위 테스트 **46/46 통과**: 성적 계산·권한·학원별 기준·복습 시간순서·동점·전송 압축의 원본 일치까지 확인했다.
- 실제 Chrome 검증 **15개 그룹 통과**, 브라우저 예외 0개. 관리자/학생 및 서로 다른 학원, 네 가지 화면 너비와 PDF를 포함한다.
- 격리된 프로덕션 빌드 성공, 디자인 토큰 검사 위반 0개.
- 개인 화면에는 관리자 변경 이력·문항 지정용 목록을 보내지 않고, 설정 화면에는 불필요한 개인 분석 자료를 만들지 않는다. 반복 날짜 포맷터를 재사용하고 JSON을 압축해 기능을 유지하면서 초기 부하를 줄였다.
- 측정 결과 및 초기 실패와 개선 기록은 같은 증거 폴더의 `PERF.md`에 남긴다.


### 2026-09-17 누락 재점검 후 추가 반영

1. 진도표의 **오답 N문항 보기**로 해당 진도의 오답 전체를 열고, 과거 회차까지 일괄 예약·재풀이할 수 있다. 현재 시험일만 남기는 제한을 이 흐름에서는 사용하지 않는다.
2. 시험에 문항 진도가 등록돼 있지만 본인의 채점이 없으면 **미응시 / 채점 자료 없음**으로 표시한다. 미래만 있으면 학습 예정이며 오답이나 0점은 생성하지 않는다. 지난 미응시 시험이 있는 경우 미래 예정 시험 때문에 그 상태를 덮지 않는다.
3. 설정 확인은 **항목 / 변경 전 / 변경 후**를 분리한다. 선택한 적용일의 기존 기준과 비교하고, 제한 시간 제거와 문항별 연결 변경도 표시한다.
4. 손실 배점 설명을 ‘채점 기록 자체가 없는 문항 제외, 제출 답안을 비운 문항 포함’으로 통일했다.

단위 테스트 49개, 추가 Chrome 검증 4개 그룹, 프로덕션 빌드 통과. 390/768/1280 화면과 상세 근거는 `.superloopy/evidence/frontend/2026-09-17-learning-followup/`에 있다. 운영 DB·배포와 실제 배점 확정은 기존 경계를 유지한다.
