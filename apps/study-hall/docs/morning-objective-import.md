# 아침모의고사 객관식 성적 가져오기

아침모의고사(`MORNING`)는 객관식만 채점·분석한다. 2026-09-14부터 추가된 O/X 문항은 가져오지 않는다.

- `Score`: `객관식` 열만 읽는다. `주관식` 점수는 총점·평균·순위·분포에 포함하지 않는다. 객관식 열이 없거나 중복이면 파일을 거부한다.
- `Errata`: 처음 1번부터 이어지는 객관식 묶음만 읽고, 번호가 다시 1번으로 시작하는 O/X 묶음부터 제외한다. 제외한 묶음의 정답·응답·O/X 채점 표시는 저장하지 않는다.
- `Moon`: 정답이 있는 객관식 행을 사용한다. 첫 묶음과 문항 수·정답이 일치해야 하며, 시험 설정의 문항 수·배점과도 대조한다. 첫 묶음을 임의로 20개로 잘라 오류를 숨기지 않는다.
- 객관식 점수를 재현하지 못하거나 객관식 정답·채점 표시에 오류가 있으면 기존처럼 확정을 막는다.
- 미리보기와 확정, mock과 DB 경로 모두 같은 카테고리 옵션을 사용한다. `REGULAR` 및 옵션 없는 파싱은 기존 전체 과목 검증을 유지한다.

## 검증

제공된 2026-09-14 채점표·문항분석표를 읽기 전용으로 검사했다. 응시인원 194명의 객관식 점수와 첫 20문항의 O 표시 수 × 5점이 전부 일치했다. 파싱·조립 결과는 경찰학 20문항, 100점 만점, 재현 불일치 0건이었다. 운영 학생 명단과의 매칭이나 운영 DB 가져오기를 실행한 결과는 아니다.

회귀 테스트는 개인정보 없는 합성 BIFF8 파일로 점수·순위·분포·결시 판단, O/X 값 제외, 객관식 오류 거부, 기존 여백 템플릿, 정기시험 검증 및 mock/DB 미리보기→확정 저장을 확인한다. 원본 파일과 개인정보는 저장소에 포함하지 않는다.
