## 검증

- TS/TSX 회귀 **463 통과**, CJS DB 동시성·금융 회귀 **30 통과**. 실행한 테스트의 실패·건너뜀 0. 자료 범위 밖 opt-in `admin-memo-local` 테스트는 제외했다.
- 로컬 PostgreSQL 실제 두 연결 경합 포함 교재/등록 롤백 테스트11개 통과. 별도 SQL로 학원·강좌·좌석·수강 상태·권한·이력 보존 확인, 검증 데이터는 ROLLBACK.
- 실제 관리자 UI: 교재 배정 → 수령 → 수령 상태에서 배정 해제 차단 → 수령 취소. 단계마다 DB 확인.
- 실제 직원 Chrome: 조회만으로 저장되지 않음 → 선택한 자료만 명시 배부 → 단일 잔여 교재 조회도 미수령 유지.
- 관리자/직원390·768·1280px 화면 확인. 문서 전체 가로 넘침 없음. 모바일 표/내비게이션의 기존 내부 스크롤은 유지.
- 새 타입 검사 및 로컬 환경의 production build 통과. 첫 빌드는 공유 개발 서버 임시 타입 파일 오류로 실패했으나 소스 변경 없이 재실행 통과했다.
- 독립 코드/보안/테스트 재검토 완료. 지적됐던 H1/T1/T2 해결 확인; 해당 수정 범위에 추가 필수 지적 없음.

## 로컬 DB 적용 내역과 운영 반영 주의

이번 로컬 DB에만 적용/기록한 버전:

1. 기존 누락분 `202605280001_material_subject_seat_gating.sql`
2. 신규 `20260905093143_material_assignment_atomic_safety.sql`
3. 신규 `20260905095307_enrollment_rollback_material_history_guard.sql`

운영 배포 전에는 운영 migration 이력을 읽기 전용으로 비교하고, 필요한 DB 변경과 앱 배포 순서를 함께 검토해야 한다. 새 앱은 새 atomic RPC를 사용하므로 **앱 코드만 먼저 배포하면 안 된다**. 기존 Vercel/Supabase 프로젝트를 유지하며 승인된 대상만 적용해야 한다. 다른 작업의 결제 migration·UI 변경을 이 보고서의 배포 대상으로 일괄 포함하지 않는다.

## 범위 밖·남은 확인

- 실제 휴대폰 카메라 권한/광학 QR 인식 및 운영 환경은 미검증. 카메라 비동기 경쟁 조건은 자동화된 실제 React 컴포넌트 테스트로 확인했다.
- QR 화면에서 미배정 교재 신규 배정, 직원의 배정 권한 확대, 수령 취소 사유/이력 보존 모델은 추가하지 않았다. 미배정 교재는 기존 관리자 교재 배정 화면에서 처리한다.
- 학생 화면의 새 배정 실시간 반영, quick/scan의 추가 abuse 방어, 전체 성능/접근성 인증은 후속 검토 사항이다.
- 기존 디자인을 유지했다. 전체 파일 토큰 검사는 기존 색상 위반10건 때문에 통과하지 않았으나 새 위반은 없었다. Lighthouse/실기기 성능 개선을 주장하지 않는다.
- DB는 앱 경로의 원자적 RPC와 권한을 보호한다. 최고 DB 권한의 임의 SQL까지 막는 전역 정책을 추가한 것은 아니다.
