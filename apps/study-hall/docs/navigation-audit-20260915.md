# 메뉴 연결 점검 (2026-09-15)

- 관리자 주요 업무 페이지: AdminSidebar의 등원 현황을 포함해 연결되어 있다.
- 설정 페이지: SettingsPageShell의 11개 설정 메뉴에 연결되어 있다.
- 운영 규칙 하위의 등원 설정은 RulesSettingsNavigation에 `등원·기기 승인`으로 추가했다. 기준·상벌점, 관리규정·휴대폰, 등원 설정에서 같은 메뉴를 사용한다.
- 공용 기기 탭에서 학생용 등원 체크 페이지를 열 수 있다.
- 학생 등록은 학생 명단의 등록 패널로, 개별 성적 분석은 성적표의 학생 이름으로 접근한다. 기존 등록·시험 유형 주소는 해당 화면으로 리다이렉트하므로 중복 메뉴를 만들지 않는다.
- 학생 메뉴는 관리규정·출석·학습 랭킹·상벌점·성적·내 정보, 조교 메뉴는 홈·출석·휴대폰을 제공한다. 학원별 기능 비활성화에 따른 숨김은 유지한다.

검증: localhost:3000에서 운영 규칙 하위 메뉴와 공용 기기 탭의 표시·접근을 확인했다. 이 점검은 운영 데이터나 기능 사용 설정을 변경하지 않는다.
